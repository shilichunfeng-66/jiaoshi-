# 阜阳师范大学 — 大创项目模块

独立完整的大创申报书生成模块,可单独复制使用。

## 模块文件

| 文件 | 作用 |
|------|------|
| `申报书-format.md` | 格式规范(字体/字号/标题层级/段落/母版分层/分点加粗) |
| `母版_申报书.docx` | 空白母版(所有边框/线型以此为底板) |
| `参考_体教融合_学练赛评.docx` | 已填好的参考申报书(内容结构参照) |
| `generate.py` | 生成脚本(博士水准分析 + 内容生成) |
| `format_apply.py` | 格式处理脚本(标题层级 + 分点加粗) |

## 使用方法

1. **生成内容**: `python generate.py`(基于母版,填入主题对应的正文)
2. **应用格式**: `python format_apply.py <生成的.docx>`(自动应用标题层级格式)

## 核心规范速查

### 字体字号
- 封面标题: 方正小标宋简体 二号
- 封面表: 宋体 四号
- 一级标题: 宋体 四号 加粗(按母版)
- 二/三级标题: 宋体 小四 加粗
- 四级标题: 宋体 小四 不加粗
- 正文: 宋体 小四

### 段落格式
- 首行缩进 2 字符 + 1.5 倍行距(标题与正文)
- 段前 6 磅 + 段后 6 磅

### 母版分层处理(铁律)
- 第一页(封面表)+ 第二页(信息/团队/教师表): 完全不动母版
- 正文(一~七章节): 母版标题保留,标题后追加正文
- 六/七(导师/学院意见): 不追加,保持母版空白

### 分点段落加粗
- "1. xxx:描述"格式 → 编号+小标题加粗,描述不加粗

### 字数
- 总字数 8000-20000,目标 12000 字
