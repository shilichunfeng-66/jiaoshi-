# 池州学院 — 大创项目模块

独立完整的大创申报书生成模块,可单独复制使用。

## 模块文件

| 文件 | 作用 |
|------|------|
| `申报书-format.md` | 格式规范(字体/字号/标题层级/段落/母版分层/分点加粗) |
| `母版_申报书.docx` | 空白母版(所有边框/线型以此为底板) |
| `参考_傩戏AIGC.docx` | 已填好的参考申报书(内容结构参照) |
| `generate.py` | 生成脚本(题目内容示例,基于池州母版生成) |
| `format_apply.py` | 格式处理脚本(标题层级 + 分点加粗,适配仿宋) |

## 使用方法

1. **生成内容**: `python generate.py`(基于池州母版,填入主题对应的正文)
2. **应用格式**: `python format_apply.py <生成的.docx>`(自动应用标题层级格式)

## 核心规范速查

### 字体字号(与阜阳师范的区别)
- 封面表: 宋体 四号
- 一级标题(一/二/三...): 仿宋 **四号(14pt)** 加粗(按母版)
- 二/三级标题((一)(二)/1./2.): 仿宋 小四 加粗
- 阶段标题(第一阶段~第四阶段): 仿宋 小四 加粗
- 正文: 仿宋 小四(区别于阜阳的宋体)

### 段落格式
- 首行缩进 2 字符 + 1.5 倍行距(标题与正文)
- 段前 6 磅 + 段后 6 磅

### 母版分层处理(铁律)
- 第一页(项目编号表0) + 封面表1 + 信息表2: **完全不动母版**
- 正文(表3): 母版标题保留,标题后追加正文
- 表3 行 2-4(八/九/十 导师/学院/学校意见): 不追加,保持母版空白

### 章节结构(10 章)
- 一、项目实施的目的、意义 (3000-3500字 重点)
- 二、项目研究内容和拟解决的关键问题 (3000-3500字 重点)
- 三、项目研究与实施的基础条件
- 四、项目实施方案(约500字)
- 五、需要学校提供的条件
- 六、预期成果
- 七、经费预算(表3行1)
- 八/九/十: 签字栏(不动)

### 字数
- 整体约 10000 字
- 一+二 6000+ 字(重点)
- 四/项目实施方案 约 500 字

### 与阜阳师范的关键差异
- **字体**: 仿宋 vs 阜阳宋体
- **一级标题**: 四号(14pt) vs 阜阳按母版
- **章节**: 10 章(含签字栏/学校意见) vs 阜阳 7 章
- **母版**: 4 表 vs 阜阳 2 表
