- **学校类型**: 公办本科
- **主管部门**: 安徽省教育厅
- **项目类型**: 大学生创新训练计划项目(国家级/省级/校级三类都适用)

## 2. 字体字号(严格规范 — 基于母版实测)

> **池州 vs 阜阳的核心区别**: 池州学院正文用**仿宋**(阜阳用宋体),字体大小与阜阳一致(小四 12pt)。

| 区域 | 字体 | 字号 | 加粗 | 缩进 | 行距 |
|------|------|------|------|------|------|
| 正文一级标题(一/二/三...) | 仿宋 | **四号(14pt)** | 加粗 | **按母版不变** | 按母版 |
| 正文二级标题((一)(二)) | 仿宋 | 小四(12pt) | **加粗** | **首行缩进2字符** | **1.5倍** |
| 正文三级标题(1. 2. 3.) | 仿宋 | 小四(12pt) | **加粗** | **首行缩进2字符** | **1.5倍** |
| 阶段标题(第一阶段~第四阶段) | 仿宋 | 小四(12pt) | 加粗 | **首行缩进2字符** | **1.5倍** |
| 正文论述部分 | 仿宋 | 小四(12pt) | — | 首行缩进2字符 | 1.5倍 |
| 封面表/信息表字段 | 宋体 | 按母版原设置 | 不动母版 | — | — |
| 母版表格标签 | 宋体 | 按母版原设置 | 不动母版 | — | — |

**页面**: 与母版完全一致(A4 / 页边距按母版原值)

## 3. 段落格式(严格统一)

**标题层级缩进与行距规则**:
- **一级标题(一/二/三...)**: 按母版原格式,不调整(章节标题,无首行缩进)
- **二级标题((一)(二))**: 首行缩进2字符 + 1.5倍行距 + 加粗
- **三级标题(1. 2. 3.)**: 首行缩进2字符 + 1.5倍行距 + 加粗
- **阶段标题(第一阶段~第四阶段)**: 首行缩进2字符 + 1.5倍行距 + 加粗
- **正文段落**: 首行缩进2字符 + 1.5倍行距

**正文段落统一设置**:
- **段前**: 6 磅
- **段后**: 6 磅
- **首行缩进**: 2 字符
- **行间距**: 1.5 倍行距
- 母版表格内的段落格式按母版原值,不修改

### 4.5 标题命名规范(先标题后内容 + 去AI化)

**构思顺序**: 先根据题目和一级标题构思全部二级标题,再构思三级标题,**标题全部锁定后才深化写内容**。

**紧扣原则**:
- 二级标题紧扣一级标题(能回答"它是这个一级标题的哪个侧面")
- 三级标题紧扣二级标题(能回答"它支撑二级标题的哪个要点")
- 答不上来即偏题,需改或删

**标题字数(2026-08-14)**:
- 三级标题(自己构思的)字数在 **5-15 字之间**,根据内容实际情况调整
- **不要都太短**(如全都 6-8 字),也不要都太长,信息量要均衡
- 示例: 10-14 字为宜,既能点明内涵又不啰嗦

**避免的标题模板**:
- ❌ "X机制:从A到B"模式(如"政策协同机制:从顶层设计到地方落地")— 模板化
- ❌ "创新点一/二/三""研究内容一/二"— 机械编号无内涵
- ❌ "1. 具有重要意义的研究""2. 关于XX问题的探讨"— 空话套话

**标题去AI化**:
- ❌ 禁用:"创新点一/二/三""研究内容一/二""具有重要意义的研究"等机械编号+泛化命名
- ✅ 要求: 每个标题根据实际内容命名,有具体内涵
- **风格**: 官方正式、书面化(不用口语大白话),但避免"赋能/抓手/闭环/范式"等 AI 味滥用词

### 分点段落加粗规则(2026-08-13)

对于"1. 小标题:描述"或"(1) 小标题:描述"这种**分点段落**(常见于"需要学校提供的条件""预期成果"等章节):
- **编号 + 小标题 + 冒号** 部分 → **加粗**(突出条目的"分点标题")
- **冒号后的描述文字** → 不加粗(正常正文)
- 整个段落仍按正文格式(首行缩进2字符 + 1.5倍行距)

示例:
- "1. **项目资金支持**:学校提供资金支持..."(加粗部分是"1. 项目资金支持:")

### 图片插入规范(2026-08-14)

> 正文生成后,按参考文件的方式在正文中穿插插入图片,紧跟相关论述,不破坏格式。

**图片数量(硬性要求)**:
- 一篇文章内图片**不得少于 5 张**,一般在 **10 张左右**,根据项目需求确定
- 不足 5 张视为不合格

**穿插位置**(紧跟相关论述,不堆文末):
- 项目简介之后 → 政策文件/背景相关图
- 研究背景/研究现状之后 → 关系图/框架图
- 研究内容之后 → 模式图/示意图
- 技术路线之后 → 技术路线图

**图片类型清单**(根据项目需求选用):
- 政策概念图、项目计划图、流程图、概念图、市场数据展示图、重要数据展示图、产品设计图、关系图/框架图/模式图/技术路线图

**图片内容分析(生成前必做)**:
- 每张图先判断"文字密度"定位: 文字配图的介绍图(政策/路线/流程→文字多)、数据图表(数据为主)、产品的展示图(产品/系统→文字少)
- 文字配图 → 文字多清晰; 产品展示 → 文字少突出外观

**穿插密度(第一原则:根据内容来)**:
- 根据内容需要配图,不为了凑数量硬插
- 不要过于密集,让图分散在正文中
- 允许两张左右图片比较接近(相邻),但不超过连续3张

**插入格式**:
- 图片**独占一个段落**
- 图片下方紧跟**图注段落**: `图N + 说明`,居中
- 图片宽度约 **11cm**(适中,不占满版),高度按比例自适应
- 图注字体: 宋体小五(10.5pt),居中

**图注编号规则(按物理顺序)**:
- 图片编号按**正文中出现顺序**从 1 开始连续编号,不分章节独立计数
- 全文第一张出现的图是"图1",依次往后,最后一张是"图N"
- 编号顺序 = 图片在文档中的物理前后顺序,不是生成顺序

**生成方式(生图渠道) — 默认 AI绘图,缺失时提醒**:
- **默认启用 `AI绘图` skill(即 nano-banana-pro,基于 Gemini 3 Pro Image)**
- 调用: `uv run {baseDir}/scripts/generate_image.py --prompt "..." --filename "..." --resolution 1K|2K|4K`
- 工作流: 1K 草稿 → 微调迭代 → 4K 定稿
- **缺失/调整时提醒用户**:
  - 未检测到 AI绘图 skill 或 API key → 主动提醒用户提供生图渠道(API key / 本地工具 / 其他接入)
  - AI绘图 skill 被调整或更换渠道 → 记录新渠道,后续按新渠道执行
- **除非用户手动调整,否则一直默认使用 AI绘图 skill**

**图片类型分工(生成方式)**:
- 所有图片默认用 AI绘图 skill 生成
- 关系图/框架图/模式图/技术路线图/流程图(文字精确) → 若 AI绘图 文字效果不佳,可退回代码/SVG
- 概念示意图/产品设计图/数据图 → AI绘图 文生图

**插入实现要点**:
- 用 `insert_paragraph_before` 在目标段后插入时,**先插图片段落、再插图注段落**,才能保证图片在上、图注在下(反之会颠倒)
- 图片插入后按物理顺序重编图注序号

**不得破坏格式**: 插入图片和图注时,沿用正文段落格式(首行缩进、行距),不改动母版边框、表格结构。

### 总字数要求(2026-08-15 严格把控)

- **目标**: 整体正文约 **10,000 字**(与阜阳师范一致)
- **重点**: 「一」+「二」两章合计 **6,000 字以上**
- **底线**: 实际填充正文(扣除 ❓未填字段)至少 **9,000 字以上**,低于 9k 即视为字数不足,必须扩充
- **不要少于需求字数太多**: 用户要 1 万字时,正文实填应稳定在 9,500-10,500 字,不能只写 8,000 字
- 生成后检查总字数,不足必须扩充
- 项目实施方案: 约 500 字(硬性,不要写多)

## 5. 母版分层处理规则(铁律 — 生成总模式)

> **核心模式**: 第一页、第二页保持母版完全不变;正文部分(表3)在母版标题骨架基础上填充内容。后续所有生成严格按此模式。

### 第一页(表0 项目编号 + 表1 封面)· 完全不动
- 表0 项目编号字段 → 留空,不动
- 表1 封面信息表的字段标签(二级学院/专业/项目名称/项目类型/项目负责人/申报日期)+ 表格结构 + 边框 → 全部保持母版原样
- ❓ 字段(二级学院/专业/负责人/申报日期等)保持空白,不填充、不加占位符

### 第二页(表2 信息表)· 完全不动
- 项目名称/项目类型/实施时间 的标签区 → 不动
- 团队表(行3-8)、指导教师表(行9-14) → 全部保持母版原样,空白处保持空白
- 仅项目名称、项目类型等**如需填写**才填入,其余不动

### 正文部分(表3)· 母版标题骨架上填充
- **一~十章节标题** → 保留母版原标题,不修改
- 在章节标题段落**之后**,追加生成的正文字段
- 追加内容严格按标题层级格式(二三级标题 + 正文段落)
- 八/九/十(导师推荐意见/学院推荐意见/学校意见) → 完全不追加,保持母版签字栏

### 永不动(贯穿全文)
- 母版表格边框(实线/虚线)
- 母版合并单元格结构(gridSpan/vMerge)
- 母版行高列宽
- 母版页边距/纸张设置
- 母版已有的标题/标签/注释文字
- 母版已有签名行/盖章行

### 只追加(正文部分)
- 一~六章节标题之后追加正文内容
- 二级/三级标题 + 正文段落
- 标题层级格式: 二级三级加粗+缩进2+1.5行距

## 7. 特殊注意事项

- **母版是唯一底板**: 所有生成完全基于母版文件,边框/线条/合并结构/标签文字永不变
- **池州用仿宋**(不是宋体)—— 与阜阳师范的核心区别
- **字体大小与阜阳一致**—— 都是小四 12pt
- **第一页和第二页不动**(2026-08-15 用户铁律)—— 只动正文(表3)
- **章节标题保留母版**: 表3 已有章节标题,只在其后追加正文段落
- **八/九/十章节不动**: 导师推荐意见、二级学院推荐意见、学校意见,母版已含签字/盖章,完全不动
- **项目类型用勾选框**: ☑创新训练项目 □创业训练项目 □创业实践项目
- **经费预算严格 10000 元**
- **字数重点**: 一+二 6k+ / 整体9k / 四500字
- **去AI味**: 生成时默认启用 humanizer(中文科研申报书适配版),嵌入生成同步处理
- **引号规则(2026-08-15)**: 用中文弯引号(""),不用英文直引号(");一篇约1万字文章引号总量≤30对,一段≤1-2对;只给特定称谓/特殊含义加引号,普通关键词不加
- **内容生成顺序**: 先构思标题(二级扣一级、三级扣二级、去AI化),再深化写内容、优化字数
