# 教师科研项目 — 独立生成技能

## 用途

本技能是「教师科研」项目类型的专属生成规则。当 orchestrator 判定用户需求属于**教师科研线**时,加载本技能并按本文件规则执行。

教师科研项目指由**高校教师主持**的纵向/横向科研课题,区别于学生主持的大创项目。教师作为主持人承担主要研究责任,学生(研究生/本科生)作为团队成员参与。

## 两个子形态(先判形态,再走流程)

| 维度 | ①教师科研/横向申报书 | ②省社科规划课题论证活页 |
|------|---------------------|------------------------|
| 典型场景 | 教师科研、横向课题、社团/联合会/协会课题申报书 | 省社科规划年度项目等官方底板类 |
| 母版来源 | 用户提供的格式文件;无要求默认阜阳大创字体 | **官方底板**(用户提供,如微信收到的活页.doc) |
| 字数 | 8000-12000 | **论证主体 ≤5000 字(硬约束)** |
| 结构 | 按格式文件章节 | 固定 7 部分: 选题依据/研究内容/思路方法/创新之处/预期成果/研究基础/参考文献 |
| 独有铁律 | 四轮梳理逻辑 | **匿名处理** + 文献 ≤20 条 |
| 配图 | 询问用户 | 一般不配图 |
| 走法 | orchestrator 步骤1-9 + 本技能规则 + 步骤10-11 | 本技能「活页子流程」(不走步骤10母版分层) |

### 执行总顺序(先看这里 · 2026-09-12 新增)

本文件篇幅较长,**按下列顺序取用即可,不必通读**;每节标题后都注明了"什么时候用"。

```
① 判形态(上表: 申报书 / 活页)
② 定题        二-A 题目符合性 → 二-C 多轮思考(七问两轮) → 二-D 主题构造与表述
③ ★双轮确认门禁 二-E 文件解读分级(轮次一) + 构建思路对齐(轮次二) —— 用户确认后才动笔
④ 研究探讨     〇 三轮研究探讨(题目解构 / 大纲论证 / 研究深化)
⑤ 正文写作     三-A 选题依据 → 三-B 研究内容与思路 → 三-G 段落写法 → 三-H 框架配比
               → 三-I 科学问题与指标对应 → 三-J 风险·合规·经费 → 三-K 复审补强
               → 三-D 研究基础 → 三-E 创新之处 → 三-C 结构范本
⑥ 文献(如文件要求)  文献实测检索铁律(orchestrator 顶部) + 编号=正文首次引用顺序、中英混排
⑦ 四道审查     三-L(Plus 三轮审核 / 项目结构审查 / 专业范围审查 / 最终六维检查)
⑧ 配图(如需要)  三-H 第 3 节 + 三-L 配图实施流程
⑨ 交付         三-L 第 3 节 12 项检查清单 + 底板合成 + 个人信息待补清单
```

> **一句话**: 定完题先**过闸门(二-E)** 再写;写完**过审查(三-L)** 再交。

## 〇 · 三轮研究探讨(默认启用 · 题目/大纲确定后、生成内容前必做)

> 三个板块(大创/教师科研/论文)共有的默认前置环节。**题目确定后、大纲确定后,在正式生成正文之前,对项目做三轮自问自答的深度探讨**——把题目吃透、把大纲论证闭环、把研究价值定位清楚,然后才动笔。三轮不可跳过、不可合并。

### 第一轮 · 题目解构(题目确定后触发)

对题目自行追问,抓取题目深度:
1. **核心概念**: 题目的每个关键词,内涵与外延是什么?有没有歧义?
2. **对象与场景**: 研究"谁、在哪、什么现象"?对象范围、地域、时间边界清晰吗?
3. **核心问题**: 把题目浓缩成一句可回答的研究问题(疑问句)?
4. **可证伪性**: 这个核心问题可证伪吗?——什么证据能推翻它?(不可证伪的命题不是科研问题,须重拟)
5. **隐含假设**: 题目隐含了哪些前提假设?这些假设站得住吗?
6. **范式专属追问**(按 orchestrator 步骤2.6 判定的科研范式,逐一核对):
   - ①调查/实证类: 自变量/因变量/控制变量是什么?测量指标与工具?样本与抽样?
   - ②实验/技术类: 实验设计可重复吗?对照组/重复数?性能指标与对照基准?
   - ③设计/工程类: 需求真实吗?交付物形态?验证方式?
   - ④政策/文献类: 文本来源权威吗?分析方法?演进脉络?
   - ⑤纯理论类: 假设命题?推导逻辑?边界条件?

→ 产出: 关键词矩阵 + 一句可证伪的核心研究问题 + 范式要素清单。答不上来 → 回选题环节重拟题。

### 第二轮 · 大纲论证(大纲确定后触发)

对已定大纲自行追问,验证论证闭环:
1. **每节论证什么**: 每个章节/模块在论证哪个关键词或研究环节?
2. **逻辑关系**: 各节之间是递进/并列/支撑?有没有跳步或断链?
3. **闭环检查**: 大纲能否完整回答第一轮的核心研究问题?有没有缺环?
4. **冗余检查**: 有没有与题目无关的自由发挥章节?

→ 产出: 论证链验证 + 大纲调整。答不上来 → 回改大纲。

### 第三轮 · 研究深化(内容生成前触发)

对研究价值与边界自行追问,定位独特性:
1. **研究价值**: 学术价值/应用价值各落在哪?评审人为什么值得给分?
2. **创新差异(基于文献)**: 与六维评分筛选出的真实核心文献相比,差异点是什么?引用具体文献作对照,不空说"与已有研究不同";
3. **研究假设/命题**(实证/理论类): 能否凝练出可检验的假设(H1/H2...)或命题?每条的变量关系/推导逻辑是什么?
4. **潜在质疑**: 评审人可能质疑什么(结论过度声称/数据不足/方法不当)?怎么回应或限定?
5. **研究边界**: 本项目"做什么、不做什么"?边界清晰吗?

→ 产出: 价值定位 + 基于文献的创新差异 + 研究假设/命题 + 质疑应对 + 边界声明。答不上来 → 回补研究设计。

### 与「四轮梳理」「二-B 思路预审」的分工(避免重复)

| 环节 | 管什么 | 时机 |
|------|--------|------|
| **三轮研究探讨**(本环节) | 题目深度 / 大纲论证 / 研究价值——"研究"层 | 题目后 → 大纲后 → 生成前 |
| 四轮梳理逻辑 | 制度/资源/时序的机制梳理——"申报书机制"层 | 生成正文时用 |
| 二-B 创作前思路预审 | 可行性/符合性/特色/价值的写作路线预审 | 写作路线确定时 |

三者维度不同、顺序衔接: 先「三轮探讨」把题目和大纲吃透 → 再「二-B 预审」确认写作路线 → 生成时套「四轮梳理」写机制。不重复、不冲突。

### 硬规则

- 三轮全部通过(有肯定结论与依据)才动笔生成内容;
- 每轮提问具体、回答有依据(真实文献/数据/政策),不空喊;
- 探讨结论以简表留存(供生成时对照,防漂移);
- 涉及的事实/文献/数据遵守反造假铁律。

## 一 · 描述逻辑核心框架(申报书/活页通用)

- **默认核心主线**:「制度协同—机制嵌入—资源节律」——制度协同(跨部门资源整合的制度安排)、机制嵌入(教师角色在课时/年限/成果间的时序衔接)、资源节律(资源按训赛/研究周期节律化供给)。
- **题目驱动升级(铁律)**: 题目出现新技术/新方法要素时,核心主线必须随之重构,不得生搬默认框架。例:《数智技术驱动下…多模态识别与保障机制研究》→ 主线升级为「数智驱动—多模态识别—保障嵌入」。升级规则: 拆题目的**驱动要素—方法核心—落脚机制**三段,分别替换主线三环,四轮梳理逻辑不变。
- **默认主线适用范围提示**: 上述默认主线源自社科/管理类(制度、机制、资源)课题,适用于教育、体育、公共管理等社科类选题;**理工科/材料/医学等选题不应套用该默认主线**,应改以「技术/方法驱动—性能/指标—验证/落地」为骨架,并走 research-paradigms 的 ②实验/技术类 或 ③设计/工程类 范式。
- 正文关键处嵌入句式: "本项目通过四轮梳理逻辑确认……"——评审人可直接看到逻辑层级,无须自行梳理。

## 一-补 · 科研质量三性(2026-09-10 用户硬性要求 · 教师科研项目必须同时满足)

> 参考文件: `reference-db/project-types/教师科研.md`(评审重点与雷区) + `reference-db/格式参考/教师科研申报书格式-中国学生体育联合会-范本.md`(高分范本写法)。教师科研项目区别于一般工作汇报/教改总结,必须同时立住三性:

| 三性 | 内涵 | 检验问句(答不上即视为不达标) |
|------|------|---------------------------|
| **理论性** | 有理论支撑与学理增量: 概念界定清晰、有理论框架或机制解释,不是做法的罗列与经验总结 | 本课题依托、回应或修正了哪个理论/学理问题?机制怎么解释? |
| **科学性** | 问题可证伪、方法可复现、数据可溯源、结论有边界(证据链完整不跳步) | 方法—数据—结论的证据链完整吗?什么条件下成立、什么条件下不成立? |
| **可实现性** | 在申报人条件(团队梯队/时间/经费/平台/样本)内真正做得完 | 每一项研究内容都对应可得的数据与人力吗?周期与预期成果匹配吗? |

**硬规则**: 三性中任一性无法给出肯定结论与依据 → 回到题目与框架层面修正,不得带着短板进入正文生成;正文各章节写作时,理论性靠"机制解释+理论引用"落点、科学性靠"证据链+结论边界"、可实现性靠"边界式描述+量化承诺"体现。

## 二 · 四轮梳理逻辑(层次保障铁律,生成与返修都用)

1. **时间型梳理**: 全生命周期节点(立项→推进→结题)时序匹配,消灭时间碎片;
2. **机构型梳理**: 教师/学院/平台/企业(或体育/教育/卫生/家庭)主体间资源嵌入方式;
3. **评审专家型梳理**: 逻辑完整性、制度合理性、资源可行性、风险可控性;
4. **专家审核轮**: 最后一轮以专家身份整体校验四轮结果,聚焦逻辑连贯与制度嵌入有效性;有问题回对应轮修正,不全文重写。

## 二-A · 题目符合性铁律(最高优先级)

> **整个文章内容必须与题目高度符合,严格围绕标题去拓展、去写作;严禁套用其他项目文件的内容来填充。**

1. **逐段锚定题目**: 每个章节、每个段落都要能回答"这段在支撑题目的哪个关键词/哪个研究环节";答不上来的段落删掉或重写,不留"通用填充段";
2. **禁止跨项目搬运**: 不得把上一个项目的背景/进展/方案文字直接搬进新题目(改几个词不算重写);历史项目文字只能作为**结构参照**,事实、数据、机制表述必须为新题目重新生成;
3. **先检索后创作**: 允许且鼓励联网查资料(政策文件、知网文献、行业数据),检索到的真实素材**围绕题目重组创造**,不是罗列——素材为题目服务,不是题目迁就素材;
4. **写前对齐自检**: 动笔前把题目拆成关键词矩阵(对象/场景/方法/机制/地域),每个关键词映射到具体章节;理工/交叉类选题另按**关键词四层**组织(方法层·对象层·技术层·机制层,每层至少 1 词,共 5 词),词库参照 NSFC 实测册;生成后回检:题目的每个关键词都在正文有实质落点,正文没有题目之外的"自由发挥"章节;
5. **违规后果**: 发现套用填充、内容与题目脱节 → 该章节作废重写;此铁律与反造假铁律同级,优先于字数/丰满度要求。

## 二-B · 创作前思路预审(动笔前必做,不可跳过)

> 在关键词矩阵对齐之后、正式写作之前,先拟一个**小型思路逻辑**(一段话级别的写作路线: 核心问题是什么 → 按什么主线展开 → 每部分打算论证什么 → 落到什么结论),然后**独立梳理两遍**,每遍过一遍四问:

| 轮次 | 侧重 | 四问(每问给出结论与依据) |
|------|------|------------------------|
| 第一遍 | **可行性+符合性** | ①是否可行——数据/方法/周期在申报人条件下做不做得到? ②是否符合题目——这条路线的每一步是否都扣着题目关键词矩阵? 有没有跑偏的环节? |
| 第二遍 | **特色+价值** | ③是否有特色——与已有研究/同类申报相比,差异点说得出吗(说不出→回主线重构)? ④是否有价值——学术价值与应用价值各落在哪,评审人为什么值得给分? |

**预审规则**:
- 两遍梳理各自独立进行(不连着顺一遍算两遍);任一问答不上来或结论为"否" → **修改思路逻辑后重新过四问**,直到四问全部有肯定结论与依据才动笔;
- 思路逻辑与四问结论以简表形式留存(供返修时对照,防止写作中途漂移);
- 正式写作中如主线调整,须回到本预审重跑两遍,不得边写边漂移。

## 二-C · 科研题目多轮思考铁律(2026-09-10 用户硬性要求 · 教师科研专属,高于通用选题流程)

> **科研项目的题目必须经过多轮思考,不得拿到方向就直接出题。** 用户给出研究方向后,先出"题目方向"再做两轮自问自答,通过后才产出候选题目。

**第一步 · 生成题目方向(不直接出题)**
基于用户给出的方向,生成 **3-5 个大概的题目方向**(方向级表述: 对象+场景+研究切入点,尚不精修成正式题目)。

**第二步 · 第一轮七问(逐方向逐一自问,每问给结论与依据)**
| # | 自问 | 不合格的处理 |
|---|------|------------|
| ① | **是否有研究价值**——学术价值(能否填补/推进已有研究)与应用价值(能否回应现实需求)各落在哪? | 说不出价值 → 淘汰 |
| ② | **是否符合实际**——政策依据、实践基础、区域/对象条件是否真实存在?是真问题还是伪需求? | 脱离实际 → 淘汰 |
| ③ | **是否能实现**——数据/样本/方法/周期/团队条件是否支撑得了? | 做不成的 → 淘汰或缩小 |
| ④ | **中外论文参考是否充足**——国内外已有文献能否支撑起这个方向(不足则方向不成立)? | 文献不足 → 淘汰(此处可联网/知网实测核查) |
| ⑤ | **是否能达到科研项目的水平**——理论深度与学理贡献够不够科研课题的格,而不是一般工作总结/教改心得? | 水平不够 → 淘汰或升维 |
| ⑥ | **方法要素是否可辨识**(题目含新技术/新方法时必问)——题目里看得出方法路径吗("驱动/辅助/基于/面向"至少落一个)? 还是只有笼统的"智能化/现代化研究"? | 方法无名无姓 → 改写或淘汰 |
| ⑦ | **能否凝练出科学/技术问题**(评委视角核心)——能否从现象提炼出一句**可检验的问题**(机制/机理类)或**明确的技术难点**(技术类)? 还是只是"要做一件事"的工作罗列? | 只有工作任务、无科学/技术问题 → 淘汰或重新凝练 |

淘汰后保留 **2-3 个方向**进入第二轮。

**第三步 · 第二轮七问(对存活方向再问一遍,更严格)**
同样的七问再走一轮,侧重**反证**: 主动找"这个方向不成立"的理由(证据够不够、有无更强竞争路线、理论根基是否站得住);本轮须额外回答两条教师科研专属问题:
- **方向延续性**: 与申请人长期研究方向、前期成果的关系是什么?是否为追热点而断裂?
- **区别性**: 与申请人已承担项目/博士学位论文的联系与区别(防重复申报)。

**第四步 · 产出候选题目**
两轮均通过的方向,抽象成 3-5 个候选题目,每个题目能回答"研究谁、在哪、什么现象、用什么材料、回答什么问题";交用户选定。

**硬规则**:
- 未经两轮七问,不得输出最终题目;
- 文献支撑不足、无法达到科研水平的题目不得进入候选;
- 优先保障研究方向的延续性,不为追热点牺牲积累;
- 用户选定题目后,仍须进入 **二-B 创作前思路预审**(两遍四问),两项不可互相替代。

> **命名参照库(双册 · 仅近三年样本)**: ①社科/人文类 → `reference-db/格式参考/社科基金题目命名规律-人民网数据库实测.md`(8 类项目定位/6 式结构/题眼词库/2025 趋势); ②理工/交叉(AI 类) → `reference-db/格式参考/NSFC结题项目实测-AI领域命名与结构分析.md`(青年·面上·重点分布/6 式命名/关键词四层写法/经费周期实测)。
> **学科适配**: 社科选题比对社科册(题名偏长,机制·路径·体系收尾);理工/交叉选题比对理工册(题名 12-25 字,方法驱动·关键技术收尾)。第⑤问"是否达到科研项目水平"按对应册比对。
> **经费周期参考(实测)**: 青年 20-30 万 / 面上约 48-60 万 / 重点 200-300 万;主流周期 3-4 年。
> **样本时效铁律**: 参照库只保留**近三年**(当前=2023-2025)立项样本;超三年的项目不采录、已在库的旧样本于年度更新时删除;每年新批次入库后复采一次(一般/青年批次发布后补)。

## 二-D · 主题构造与题目表述精华(2026-09-10 从项目元数据反推 · 拟题直接用)

> 来源：NSFC 结题库"人工智能"100 项元数据片段（题目/关键词/类别/经费/年度，**不含正文**）反推的四条精华。适用于所有学科——先择路径，再套定式，最后校层级。

1. **主题构造三路径(先选路径再拟题)**:
   | 路径 | 模式 | 适用 |
   |------|------|------|
   | 技术驱动型 | `[方法] + 驱动的 + [对象] + [动作]` | 有明确新技术抓手 |
   | 场景问题型 | `面向 + [真实场景/任务] + 的 + [方法] + [技术] + 研究` | 有明确应用场景与痛点 |
   | 机制解释型 | `[现象/技术] + 对 + [对象] + 的 + 影响机制/机理 + 研究` | 社科/管理/行为交叉 |
   → 三选一,不许混搭(技术与对策混杂、机制与路径并置都是典型失分点);选定后题目、关键词、研究内容统一口径。
2. **题目=四要素定式**: `方法词(驱动/辅助/基于/面向,四选一不叠加) + 研究对象 + 研究动作 + 落点后缀`;技术类后缀用"关键技术研究/方法研究/模型构建",机制类用"影响机制研究/机理研究/量化评估";社科类题名可长(20-30 字),理工/交叉类宜短(12-25 字)。
3. **关键词=四层五词**: 方法层 1 + 对象层 1-2 + 技术层 1 + 机制层 1,按层级顺序排列,禁止同层堆叠(全写深度学习/机器学习/神经网络即失分);词库取参照册真实高频词。
4. **类别—经费—周期对应研究颗粒度**:
   | 类别 | 经费 | 周期 | 颗粒度 |
   |------|------|------|--------|
   | 青年基金 | 20-30 万 | 3 年 | 单一问题做深 |
   | 面上项目 | 48-60 万 | 3-4 年 | 2-3 个问题成链 |
   | 重点/重大 | 200-300 万 | 4-5 年 | 体系化构建 |
   → 研究内容颗粒度必须与申报层级匹配(青年项目写"体系构建"、重点项目只做单点,均属层级错配)。
5. **载体适配与字数**:
   | 载体 | 题名长度 | 附加要求 |
   |------|---------|---------|
   | 活页 / 申报书(社科) | 20-30 字 | 机制·路径·体系收尾;匿名,不得出现单位与个人信息 |
   | 活页 / 申报书(理工交叉) | 12-25 字 | 方法驱动、"关键技术研究"收尾 |
   | 横向课题 | 可含合作方/区域限定 | 体现委托方需求或应用场景 |
   | 论文 | 20-25 字 | 与研究问题、结论呼应,避免"XX研究"泛化 |
6. **学科归属先于表述**(跨学科选题): 同一选题可对应不同学科口径(实测 AI 类项目分布于 9 个申请代码大类)——**先定落点学科/申请代码,再据此定题目表述**;申报前对照当年学科目录(如体育学科 2025 起为"体育学与健康管理")。学科口径影响评审口径,题目的落点词要跟着学科走。
7. **一题三稿法**: ①**方向稿**(对象+问题,不追求精修) → ②**定式稿**(套四要素定式) → ③**精修稿**(删冗词、统一动词、核对字数与学科落点);三稿留存,便于回退比较,避免在终稿上反复涂改。

## 二-E · 双轮确认门禁(2026-09-12 用户硬性要求 · 定题后、动笔前必做,不可跳过)

> **为什么要有这一节**: 教师科研项目的底板/通知五花八门,每份文件规定的填写部分、篇幅与评审侧重都不同。动笔前若没把"**文件到底要什么、哪些是重点**"和"**整体构建思路**"跟用户对齐,极易出现两种翻车——**用力错位**(在次要部分堆字、在重点部分写浅)与**方向跑偏**(写完才发现要解决的问题不是用户想做的)。故设两道确认闸门:**用户未确认,不得进入写作**。

### 触发时机
- 题目(或候选题目)已确定 **且** 拿到项目文件(申报书底板 .doc/.docx、申报通知、模板说明、评审要求)之后;
- 用户只给方向、还没定题 → 先走 二-C/二-D 定题,再进本节;
- 用户**未提供文件** → 只做「轮次二·构建思路对齐」,分级按本节兜底优先级执行,并明确告知用户"未提供文件,按通用重点排序,拿到文件后可回来调整"。

### 轮次一 · 文件解读与重点分级(先分级,再确认)

**第 1 步 · 提取"大方向"**: 逐条抄出文件规定的一级填写部分——**原文照录,不改写、不归并**。
> 例(社团/联合会类课题"三、课题设计论证"): `1.选题依据　2.研究内容　3.思路方法　4.创新之处　5.预期成果`

**第 2 步 · 提取"小方向"**: 每个大方向后括号或说明里的具体要求**逐条拆出**,这些就是该部分的**写作任务清单**。
> 例: `1.选题依据: 国内外相关研究学术史梳理及研究动态;本课题相对已有研究的独到学术价值和应用价值等。`
> → 拆成 3 条小方向: ①学术史梳理 ②研究动态 ③独到学术价值与应用价值

**第 3 步 · 判优先级(三分档)**

| 档位 | 判据(满足任一即入该档) | 处理方式 |
|------|----------------------|---------|
| **重点** | ①文件对该部分说明文字最多、要求最细 ②含"梳理/凝练/构建/设计/论证/评价"等实义动词 ③属"研究什么·怎么研究" | 写足写透,重点档合计占篇幅 **60-75%** |
| **一般** | ①有明确要求但篇幅有限 ②属"为什么做 / 价值在哪" | 写实但克制,一段到位、给依据 |
| **有就行** | ①文件中一句带过,或措辞是"说明/简介/安排/保障" ②程序性内容 | 写清即可,杜绝堆字 |

**通用兜底优先级(文件未明示时按此;文件有明确要求 → 一律以文件为准)**

```
第一档(最重)  研究内容 · 研究方案 · 项目内容 · 项目方案      —— "做什么、怎么做",永远最重
第二档        研究目的 · 意义 · 价值 · 选题依据              —— "为什么做、值不值得做"
第三档        思路方法 · 技术路线 · 创新之处 · 特色          —— "用什么办法、新在哪"
第四档(有就行) 预期成果 · 进度安排 · 条件保障 · 团队分工 · 经费说明 —— 清楚可信、不啰嗦
```
> ⚠️ **两个易错点**: ①"目的/意义/价值"不是次要项——它常与"选题依据"合并出现,是评委判断"该不该做"的直接依据,须写实、给依据,不能只喊口号; ②"研究内容/方案"一档最重,但**篇幅要跟着文件的字数约束走**(如活页论证主体 ≤5000 字,重点档也不能超总盘子)。

**第 4 步 · 输出「重点分级确认表」发给用户,请其确认或修改**

| 序 | 文件规定部分 | 文件原话要求(小方向,摘录) | 分级 | 拟投入篇幅 | 拟写要点(一句话) | 备注 |
|----|-------------|--------------------------|------|-----------|-----------------|------|
| 1 | 选题依据 | 学术史梳理 + 研究动态 + 独到学术价值/应用价值 | 一般 | 约 1200 字 | 三条线索收口到三点局限,反证本课题价值 | — |
| 2 | 研究内容 | 研究对象/总体框架/重点难点/主要目标 | **重点** | 约 1300 字 | 三环递进 + "目标—内容—指标—方法"四列对应 | — |
| … | | | | | | |

发出时必须配三句话:
1. "以上为我对文件的理解,**请你确认或调整**: 增删部分、调换主次、改字数均可;"
2. 文件里的**硬约束单列一行**提示(总字数上限 / 匿名要求 / 文献条数上限 / 是否配图);
3. 文件里**本课题不适用或无内容**的部分,标注"建议写简"并给一句理由。

**硬规则**: 未收到用户对分级表的确认(或修改后再确认),**不得进入轮次二之后的写作**。

### 轮次二 · 整体构建思路对齐(一句话能说清全项目)

分级确认后,用**四问**与用户对齐整体构建思路——**一次性问清、不逐条追问**;**每问都给"我的建议方案"(带默认值)供用户直接改**,不空问。

| # | 对齐项 | 要说到什么程度 | 示例口径 |
|---|--------|---------------|---------|
| ① | **项目题目** | 定稿写法(对象 + 落点),与母版标题、文件名一致 | 《体医融合视域下大学生体质弱势群体运动干预模式构建与应用研究》 |
| ② | **研究什么 / 重点解决什么问题** | 1-3 句: 研究什么 + 核心难点或要凝练的科学/技术问题 | 分层标准缺失、体育与校医各管一段、过程评价缺失 |
| ③ | **打算怎么解决** | 研究主线 + 关键方法/路径 + 分几个阶段(与"研究内容/研究方案"呼应) | 识别—构建—应用三环 + 准实验 + 22 个月四阶段 |
| ④ | **最终成果** | 最终产出形式 + 给谁用 / 产生什么效益 | 干预模式 + 分层工具表 + 操作手册 + 论文与总报告 |

**确认单**: 用户确认后,落一份「**构建思路确认单**」(四问四答,存 `outputs/`),作为后续所有章节与审查的**唯一口径基准**——正文若与确认单不一致,**以确认单为准并回改正文**。

### 两道闸门的输出物与衔接
- **输出物**: ①「重点分级确认表」(含用户修改痕迹) ②「构建思路确认单」;
- **衔接**: 二-E 完成后才进入 `〇 三轮研究探讨` → `三-A~三-K 写作`;
- **追加纪律**: 写作中若用户新增要求、或文件有补充通知 → **先回改确认单,再改正文**,避免"确认单与正文两张皮"。

## 三 · 活页子流程(省社科规划课题论证活页等官方底板类)

> **前置**: 本子流程第 1 步“底板解读”须与「**二-E 双轮确认门禁**」轮次一联动——先出「重点分级确认表」交用户确认,再动笔。

1. **底板解读**: 用 Word COM/编辑器读官方底板(.doc/.docx),产出框架清单——页首标题字体/表格结构(如2行1列: 行1课题名称/行2内容区)/内容区字体字号行距/说明文字位置;
2. **信息分类(含匿名矩阵)**: 底板硬约束逐条提取——总字数上限(如≤5000)、文献上限(≤20)、**匿名要求**(研究基础只填成果名称/形式/作者排序/是否核心期刊,**不填姓名/单位/刊物/时间**;正文不透露个人信息;申请人前期成果不列入参考文献)、说明文字"填写后删除"标记;
3. **内容生成**: 严格按底板固定部分组织(非套用其他项目文字),按上方描述逻辑框架+四轮梳理写,学术写作+去AI味同步;「选题依据」部分按三-A三层漏斗框架执行;❓字段(作者排序/核心期刊等)不代填,留[待补充];
4. **文献实测**: 按 orchestrator 顶部「文献实测检索铁律」走知网检索,条目数 ≤ 底板上限(默认 10 条左右,动笔前询问用户条数);**文献口径**: 以核心期刊论文为主;社团/联合会类课题可含会议论文集[A]/[C]与学位论文[D](范本实证),但每条均须知网实测核实真实存在,禁网页/自媒体/百科;
5. **匿名校验**: 全文扫描——无姓名/单位/刊物名/发表时间(研究基础区),引用锚点 ⊆ 文献表;
6. **底板合成(不解构母版)**: Word COM 打开底板→课题名称单元格填入(加粗)→内容区清空写入→逐段格式化(段首标签加粗、正文首行缩进2字符、行距沿用底板)→删除说明文字→另存 docx。**绝不改动底板的页首标题/边框/表格骨架**。

> **字数铁律**: 活页论证主体 ≤5000 字,不套用 orchestrator 步骤 8D 的 8000-20000 字要求。

## 三-A · 选题依据三层漏斗写作框架(活页/申报书/论文通用)

> 适用: 活页「选题依据」/ 申报书「立项依据·研究现状」/ 论文「引言·文献综述」。深度解剖见 `reference-db/选题依据写作框架-高分范本分析.md`。

**总公式: 选题依据 = 问题提出(六步链) + 学术史(N线法) + 研究动态(升维+N局限+收口)**;价值论证不单设小节,通过"局限→本课题"对接隐含完成。

1. **(一)问题的提出 — 六步链单段成文**: 政策场景(具体战略命名,禁"近年来…发展"空话) → 对象重要性 → 问题链条具体化(阶段+具体表现,如"训练、对抗竞赛、赛后及休赛转换周期"+具体风险名词) → 利害升级(不做的后果) → 技术条件变化(题目方法要素以现实条件身份自然出场,不硬塞) → 实践缺口(对应题目落点) → 落题句(一句话嵌入题目全部关键词)。
2. **(二)学术史梳理 — N线法**(N=题目关键词模块数,对象/方法/机制三段式题目 N=3):
   - 总起句先给"文献版题目"地图(N 个议题=题目关键词模块);
   - 每线四件套: **述**(国内文献+国外文献+申请人自引[匿名化"申请人(年份)"],每线3-4篇,文献紧跟观点) + **评**(一句局限收口);
   - **局限递进收窄**: 各线局限朝本课题研究空间逐级逼近(场域不足→地方实证缺乏→完整链条缺失),缺口终点=本课题起点;
   - 文献功能分工: 国内给"类型划分/本土发现",国外给"机理印证+普适结论",不凑数罗列。
3. **(三)研究动态 — 升维评判**: 不重复梳理,换学科视角坐标系把 N 条线压缩为 2-3 条已有共识 → "其一…其二…其三…"三局限(汇总升级而非重复,最后一条直接嵌入本课题主线词组,如"缺少『风险识别-制约因素-保障机制』完整链条研究") → 关键局限句**加粗**(评审30秒扫读可抓核心缺口) → 一句收口"本课题即是在此背景下进行的"。
4. **环绕主题四机制(写后回检)**: ①镜像——N条文献线=题目关键词模块; ②缺口对齐——局限终点=课题起点; ③三重收口——问题提出末句/每线末句/动态末句均落回本课题; ④关键词全埋点——题目每个关键词在正文有实质落点并在落题句一次性回收。
5. **硬规则**: 禁"研究很多/很少"空评,每句局限具体到"缺什么场域/对象/链条";所有文献走知网实测铁律;字数按文档配额缩放但三层结构与四件套不变。

## 三-B · 研究内容与思路方法写作模板

**② 研究内容 — 主线模块法**:
1. 总起段一句话: "本研究围绕{核心主线}展开,设置{N}个相互衔接的研究内容"(N=3-4,与主线三环对应);
2. 每模块固定三要素: **具体命名**(按实际内容命名,禁"研究内容一"式机械编号) + 干什么(研究对象+动作) + 产出什么(为后续模块或结论提供什么);
3. 模块间写明**递进关系**: 前一模块的产出是后一模块的输入(如"现状摸底→风险识别→机制构建→验证应用");
4. 每模块 80-150 字,写完逐模块回检"支撑题目哪个关键词"。

**③ 思路方法 — 链条对映法**:
1. 总起: 一句话研究思路(链条式,沿主线),再"具体分{N}步推进";
2. **步骤与内容模块一一对应**,每步 = 方法 + 对象 + 产出,禁止出现内容里没有的步骤;
3. 常用表述链条: 现状调查 → 机制/成因分析 → 模型/框架构建 → 案例或区域验证 → 对策形成;
4. 方法写实: 用了什么方法(文献/问卷/访谈/案例/统计)写清"方法+对象+数据用途",不堆方法名词;
5. 回检三问: 每步可执行吗?周期内排得开吗?每步产出能挂到预期成果吗?
6. 可配一张技术路线图(流程式,主线为轴)。

> 上述两模板与三-A 选题依据三层漏斗共同构成正文前三部分的逐段写作依据;②③的模块/步骤划分必须在关键词矩阵中有落点。

**内容描述方式提炼(范本实测 · 可复用句式)**:
- 现状描述: 国外一段(研究深入方向)→国内一段(政策+体系+空白), **短段落+分点**, 不用长排比;
- 价值论证: 分 (1)学术价值 (2)应用价值, 各一段**独立成节**(不与其他内容混排), 学术价值落"填补…/提供理论支撑", 应用价值落"以…为重点, 通过…探索新经验/新模式/新路径"三段式动宾链; ⚠️**高频失分点**: 把两块价值压成一段百来字——评审据此判断"该不该做", 须写足(各 180-250 字), 并落到可识别的分层框架/模式结构/可复制方案等具体贡献;
- 研究内容: **边界式描述**——每条"重点研究什么 + 暂不涉及什么", 用"不再全面涉及/暂不深入探讨/暂不涉及复杂技术"划定可行范围, 让评审看到可控性;
- 研究计划: **时间轴+动作清单**——按"第一个学期(前1个月)/(后2个月)/暑假/第二学期…"分段, 每段列 3-5 个具体动作(定方案/筛选分组/准备器材/培训/教学/测试/问卷/比赛/整理分析);
- 可行性: 落到具体资源(课程安排/成员专长/场地设备), 给出可验证的量化承诺(如"每4周一次小型比赛""参与人数200人以上");
- 人员描述: 负责人"姓名+领域+长期从事+发表论文具名列举"; 成员按"骨干教师+研究生+本科生"梯队分工;
- 创新之处: 固定三类(学术思想/研究方法/成果应用)各一条, 每条"结合点+效果"一句话;
- 成果表述: 全部具名(书名号全称), 与成果表逐字对应。

## 三-G · 正文段落写作模板与句式库(2026-09-10 补 · 段落级写法)
> 通用总纲：`reference-db/格式参考/正文写作技法总纲.md`(题目—内容逻辑三层锁定 / 描述方式八法 / 思考层数 L0-L4 / 三线差异对照);本节为教师科研场景的段落级落地。


> 三-A/三-B 解决"每节写什么",本节解决"**每段怎么写**"。适用活页论证、申报书正文、论文正文。

### 1. 论证段落四步法(每个论证段落都按此展开)
```
① 论点句(本段要说什么,一句话立住)
② 展开/论据(为什么这么说:机理推导、政策依据、文献支撑)
③ 例证或数据(用什么证明:真实文献结论、调研数据、案例事实)
④ 回扣题目(一句话收口,点明本段支撑题目哪个关键词/哪个环节)
```
**要点**: ②③ 不可省——只有 ①④ 的段落就是空话;④ 允许隐含在语气中,但**结构上必须存在**;一段只说一件事,说两件就拆段。

### 2. 节内"述—评—转"衔接句式库
| 环节 | 作用 | 句式 |
|------|------|------|
| 述 | 概括已有进展 | "现有研究主要在{A}、{B}两方面展开,形成了{共识}。" |
| 评 | 指出局限(朝本课题留缺口) | "但这类成果多基于{C}场景,对{D}的真实场域考察不足。" |
| 转 | 过渡到本课题 | "本课题正是针对该缺口,围绕{E}展开。" |
> 每条文献线、每个现状小节都以"述→评→转"收束,不用"综上所述"作万能过渡。

### 3. 数据与证据呈现句式
- **表前引导**("为考察…,本研究从{N}个维度设计调研,结果见表3-1。");
- **表后解读**("调查结果表明,…占比最高({X}%),其次为…({Y}%);反映出{结论}。")——百分比与表内一致,不重复罗列表格全部数字;
- **质性印证**("访谈发现,…",与数据互补,不用来替代数据);
- **文献引用**("已有实证显示…(作者, 年份)",紧跟观点,不堆砌文末;
- **反证与限定**("该结论在{A}条件下成立,当{B}时需谨慎推广")——**结论有边界**即科学性所在。

### 4. 理论引用与机制解释句式
- 引用要给**用途**而非装饰: "借鉴{理论}的{概念}来解释{A}的成因,即…";
- 机制解释用"**因为—所以—因此**"链条写足三层: "之所以出现{A},源于{B}的作用;当{C}发生变化时,{A}随之改变,因此{对策/设计}应落在{C}上。"
- 禁"借鉴了XX理论"一句话空转(此为理论性不达标的典型)。

### 5. 篇幅节奏与详略
- 论证主体(选题依据+研究内容+思路方法)约占总篇幅 **65%-75%**,创新与成果各 10% 左右;
- 重点层层展开(3-5 段),边缘层一句话带过;
- **忌平均用力**: 每节等长说明没有重点,评审看不到核心。

### 6. 段落自检三问(写完全文逐段过)
① 本段论点一句话说得出来吗? ② 证据(文献/数据/事实)够不够? ③ 这段扣题目哪个关键词? —— 三问答不上任何一个,该段重写或删除。

### 7. 申报书正文 AI 腔黑名单(humanizer 场景适配)
- 开头套路: "随着…的不断发展/飞速发展" → 改为**具体政策或现实事实**开篇;
- 空转大词: 赋能、抓手、闭环、范式、生态位(非必要不用);"具有重要意义/深远影响"→ 写明**对谁、有何用**;
- 假靶子句式: "不是A,而是B"(滥用时);机械三段式("首先…其次…最后…"通篇);
- 万能过渡: "综上所述""由此可见""值得注意的是" 高频出现 → 换成具体回扣句;
- 结尾: "为…提供了有力支撑" → 换成"可为{主体}在{场景}中{动作}提供参考"。
> 写完正文后按 orchestrator 步骤 8E(学术写作)→ 8F(去AI味)顺序各过一遍,本清单为 8F 在申报书场景的补充词表。

## 三-H · 正文框架补强(篇幅配比 / 开篇收尾 / 图表说明 / 可行性 / 教师特色入文)

### 1. 篇幅配比(建议区间,按底板实际字数等比缩放)

|------|---------------------|-------------------|
| 选题依据 | 1200-1500 | 2000-2800 |
| 研究内容 | 1000-1300 | 2200-3000 |
| 思路方法(含计划与可行性) | 1100-1400 | 2000-2800 |
| 创新之处 | 300-450 | 500-800 |
| 预期成果 | 250-400 | 500-800 |
| 研究基础与条件保障(非匿名区) | 不计入论证主体 | 1200-1800 |

### 2. 部分开篇与收尾定式
- **开篇三选一**(禁"近年来…"式起头): ①**政策或现实事实**起(点名具体战略/文件/事件) ②**已有研究概括**起("现有研究主要在…") ③**概念界定**起(先立本课题的核心概念);
- **开篇第一句必须出现题目关键词之一**——开篇即锚题;
- **收尾两句式**: ①回扣式("因此,{关键词}的{机制/路径}亟待厘清。") ②衔接式("上述缺口指向{下一部分主题},故下文先…");
- **每部分末句回扣题目**一次(呼应二-A 逐段锚定)。

### 3. 图与表的文字说明
- **图前引导句**: "基于上述思路,本课题的{技术路线/框架}如图 1 所示。"
- **图后解读句**: "该{路线/框架}以{主线}为轴,各环节分别对应{内容模块},前后形成{递进/反馈}关系。"
- **表前引导 / 表后说明**(成果表、经费表、时间轴表): "预期成果与时间安排见表 N;成果名称与研究内容一一对应。"
- **铁律**: 图表必须在正文被引用("如图 X/见表 X"),不孤立出现;图注在下、表注在上;图内文字与正文表述一致。
- **配图实施流程(2026-09-11 实测固化)**: ①先判断"是否必要"——只画表达**想法/框架、方案/重点、过程/流程、计划/产出**的图,凑数图与无数据支撑的"效果对比图"一律不加(未实测不得绘制数据图);②**总数不超过 5 张**;③结构类图用代码绘制(matplotlib 300dpi/白底/学术蓝绿/中文标签),不用 AI 生图(避免错字);④插入方式: 以用户定稿版 docx 为底板,用 python-docx 在目标段落前 `insert_paragraph_before` 依次插入"图片段+图注段"(图片居中宽 14.5cm,图注宋体小五居中),按物理顺序编号,不改动底板结构与既有文字格式;⑤插入后回读校验"图片数=图注数"及插入位置。

### 4. 可行性论证三段论
`① 条件具备 → ② 路径清晰 → ③ 风险可控`:
"在{人/物/时间}条件上,依托{平台/团队}具备…(条件);研究路径已有{前期基础/成熟方法}支撑…(路径);针对{最可能的风险点},已准备{替代方案/调整机制}…(风险)。"
> 只写"条件良好"不给依据 = 不达标;每个优势都要落到具体资源或前期成果。

### 5. 教师特色要素入文(科教融合 / 团队 / 条件)
- **科教融合**: "研究成果将反哺{课程}教学,形成{教学案例/教材/实验项目},实现科研与教学的双向支撑。"
- **团队梯队**: "课题组建{职称·学位}梯队:由{骨干}负责{模块},{研究生}承担{数据采集/实验实施}环节,任务可分解、责任可落实。"
- **平台条件**: "依托{实验室/基地/中心}的{设备/数据/样本}条件,确保{关键环节}可实施、可复现。"
> 三类句式同时服务评审重点(团队配置、平台支撑)与三-D 条件保障;论证部分点到、基础部分展开,勿重复堆砌。

## 三-I · 科学问题与"目标—内容—指标—方法"对应(评委视角核心)

### 1. 科学问题凝练三步(对标国自然评审的第一关注点)
```
现象(观察到的事实/矛盾) → 疑问(为什么?在什么条件下?) → 科学问题(一句可检验的命题式问题)
```
- **三问区分**(评委据此判断申报书属性): **科学问题**(为什么/机制如何) · **技术问题**(怎么做/性能能否达到) · **工作问题**(要做什么/任务安排);
- 申报书应以**科学/技术问题**立骨,工作问题只作支撑;通篇都是工作问题 = 被判定"缺乏科学问题";
- 句式: "{X} 通过 {Y} 影响/作用于 {Z} 的{机制/机理}是什么" 或 "在 {条件} 下,{X} 能否/如何{达到某性能}"。

### 2. "目标—内容—指标—方法"四列对应表(逐行对齐,缺一行即被质疑)
| 研究目标(可考核) | 对应研究内容 | 可验证指标 | 采用方法 |
|-----------------|-------------|-----------|---------|
| 目标 1(2-4 个;青年 1-2 个) | 内容模块 1 | 量化/可判定指标 | 方法 1 |
| … | … | … | … |

**规则**: 每个目标有内容承接 · 每项内容有指标兜底 · 每个指标有方法产出 · 不得出现"孤儿行"。

### 3. 关键问题与对策配对(2-3 条)
每条写足三句: **难点是什么**(科学/技术层面) → **拟解决途径**(用什么思路/方法) → **预期突破点**(突破了会怎样)。

### 4. 题目承诺一致性检查(评委最常挑的毛病)
题目的每个承诺词(机制/路径/体系/模式/关键技术)都必须在目标与内容中**有兑现**;题目大而内容小 = 层级错配 → 改题或补内容。反向亦然:内容承诺了体系而题目只写"初步探索",同样不一致。

## 三-J · 风险预案 · 伦理合规 · 经费匹配 · 评审自检

### 1. 风险与预案(清单式,回答评委"如果拿不到数据怎么办")
| 风险点 | 触发情形 | 预案 |
|--------|---------|------|
| 数据/样本获取 | 合作单位变动、回收率不足 | 备用渠道 · 扩大抽样 · 替代数据源(公开库/二手数据) |
| 方法风险 | 方法不适用、效果不显著 | 备选方法 · 缩小范围 · 调整假设 |
| 进度风险 | 关键环节延误 | 预留缓冲期 · 并行推进 · 阶段成果先行发表 |
| 人员风险 | 骨干成员变动 | 关键模块双人负责 · 流程文档化 |

### 2. 伦理与合规(涉人、涉数据研究必写)
知情同意与自愿参与 · 伦理审查(涉人研究须报批) · 数据脱敏与加密存储 · 个人信息保护(遵循个人信息保护相关法律) · 学生/儿童等特殊群体的额外保护措施。

### 3. 经费与研究内容匹配(评委必查)
每个支出科目都能指到具体用途: 资料费↔文献资料; 数据采集费↔问卷/访谈/购买数据; 差旅费↔调研地点与次数; 专家咨询费↔咨询或德尔菲轮次; 劳务费↔参与学生工作量。**禁"有科目无用途"**。

### 4. 评审追问八问自检(模拟函评,逐问书面作答)
① 科学问题是什么? ② 与已有研究相比新在哪? ③ 目标能否考核? ④ 关键难点如何突破? ⑤ 数据/样本从哪来、够不够? ⑥ 团队与平台能否支撑? ⑦ 成果是否可达、承诺是否过高? ⑧ 与已承担项目是否重复?

### 5. 指标承诺—可达性平衡
指标要有挑战性但可达(青年项目忌承诺"体系构建 + 全国推广");采用分级表述("预期完成/力争实现/可为…提供参考");禁"国际领先/填补空白"式过度声称。

## 三-K · 复审补强(第二轮评审核查项)

### 1. 国际对标规则
学术史梳理不能只列国内: 须设**国外研究线**,并给出**国际比较基准**——对标哪个国家/机构的哪种做法、哪套标准、哪类数据,再指出现有国际研究在本土情境下的不适用之处。只写"国外研究较为深入"属于无效对标。
**国际对标检索入口**: 中文文献走知网实测(BrowserSkill);英文文献走 Web of Science / Scopus / Google Scholar(可用机构库或开放获取版本),核刊可用 JCR 分区与中科院分区判断层级;检索式模板: `"主题词英文" AND (framework OR mechanism OR intervention) AND (country/region)`。对标结论须落到"国外做到哪一步、标准是什么、本土为何不适用"三句。

### 2. 匿名活页的"能力证明"三步法(匿名与积累的两难)
活页既要匿名,又要让评委看到申请人做得了,按三步写:
1. **第三人称口径**: 统一用"课题组/申请人"表述,不出现姓名、单位、地域性唯一标识;
2. **成果证明**: 写已完成的前期成果**名称 + 形式(论文/报告/专利) + 排序**,不写刊物名与发表时间;
3. **条件佐证**: 以"已具备的{平台类型/数据积累/合作基础}"证明实施条件,平台与单位做匿名化描述(如"依托省内高校体育教学实验平台")。

### 3. 研究内容—时间—指标三列对应(评委查进度合理性)
| 研究内容模块 | 起止时间 | 阶段指标/阶段成果 | 承担角色 |
|-------------|---------|-----------------|---------|
| 模块 1 | 第 1-{n} 月 | 阶段产出(可判定) | 主持人 / 骨干 / 研究生 |
规则: 时间总量与申报周期一致;每个模块都有阶段指标;不留"只有开始没有产出"的空段。

### 4. 引用—论断呼应规则
每个关键论断(机制主张、现状判断、价值判断)必须有**引用或数据**支撑;引用之后须有推论句("据此可推知…""这说明…"),杜绝"引而未用"(文献列了,但论断仍悬空)。评审常据此判断"文献是装饰还是论证"。

### 5. 评审自评量表(生成后自评,低于 3 分必须改进)
| 维度 | 1-5 分 | 打分依据(写具体) |
|------|-------|----------------|
| 选题价值 | | 政策契合度 + 现实需求强度 |
| 论证充分 | | 现状是否清、问题是否准、缺口是否指向本课题 |
| 方案可行 | | 目标—内容—指标—方法是否对齐,风险是否有预案 |
| 创新性 | | 与已有研究的差异点能否一句话说清 |
| 基础条件 | | 前期成果相关性 + 团队与平台支撑 |
> **自评量表模板**: `reference-db/格式参考/评审自评量表-模板.md`(五维打分 + 打分依据 + 评审追问八问 + 回检结果粘贴位);自评结论随稿留存,任一维度 < 3 分 → 回到对应章节修改后重评;总分 < 20 分不建议提交。
> **自动化回检工具**: `tools/check_doc.py 稿件.md [--anonymous] [--min-chars N]` —— 自动校验字数、文献编号 1→N 正序、正文 `[n]` ⊆ 文献表、匿名可疑项(姓名/单位/邮箱/手机/身份证)、禁词与 AI 腔句式;有"问题"时退出码为 1,可直接接入流程作为生成后的硬门槛。

### 6. 团队—模块对应(评委查"人岗匹配")
成员(或匿名角色)↔ 内容模块 ↔ 产出三者对应,避免"团队名单与任务无关";骨干负责攻关模块,研究生承担数据与实验环节,角色分工与研究内容一一挂钩(与三-H 第 5 条配合使用)。

## 三-L · 全流程生产与交付检查清单(2026-09-11 体医融合项目实战沉淀)

> 来源：中国学生体育联合会课题《体医融合视域下大学生体质弱势群体运动干预模式构建与应用研究》全流程案例（详见 `outputs/教师科研线_项目全流程制作报告_体医融合案例.md`）。**同类项目按下述顺序执行，交付前逐条跑完 13 项检查，并执行第 6-9 节的反查、交付、精简与编辑规范。**

### 1. 端到端顺序(建议照做)
判定线别 → 题目(二-C 七问 / 二-D 定式) → **二-E 双轮确认门禁(文件解读分级 + 构建思路对齐, 用户确认后才动笔)** → 文献实测(含顺序与口径) → 底板解析 → 论证生成(三-A/B/I/H) → Plus 三轮审核 → 项目结构审查 → 专业范围审查 → 文献规范复核 → 配图(三-H 配图流程) → 最终六维检查 → 交付＋待补清单。

### 2. 四道审查缺一不可(本次共揪出 12 处问题)
| 审查 | 查什么 | 本次实获 |
|------|--------|---------|
| Plus 三轮审核 | 评审专家视角: 结构内容 → 逻辑学术 → 细节表述 | 13 条(含引用错位/模式未界定/创新未回应局限/伦理缺失/风险笼统) |
| 项目结构审查 | 主体·论点·核心·解决什么·怎么解决·概念清晰度·一致性 | 7 处(含周期三方冲突/12周与阶段时长矛盾/对照组只在方法里/双轨结构未打通) |
| **专业范围审查** | 是否越出申报人专业(如体育+运动康复 vs 纯医学) | 1 处明显越界 + 4 处偏医学 |
| 最终六维检查 | 结构/内容/文献/口径/数字/工具 | 3 处补漏(缺参考文献标题/单段软换行/成果形式空缺) |

### 3. 交付前 13 项检查清单
1. 题目含"对象+场景或视角+研究落点",能凝练一句科学问题;
2. 研究对象与分层口径写清,无专业越界表述;
3. 论点分组数量明确,与"三点局限"或"三环"逐条对应;
4. 核心命题 + 核心产出(模式/方案/工具)各一句话;
5. 目标—内容—指标—方法四列对齐,无孤儿行;
6. 方法·样本量·对照组·周期·可行性(含风险预案)齐全;
7. 涉人研究写明知情同意与数据处理;
8. 专业边界: 不涉疾病诊断·药物治疗·临床疗效评价(必要时加"研究边界声明");
9. 数字四处一致: 研究周期 ↔ 成果时间 ↔ 年度预算 ↔ 科目合计;
10. 文献: 条数·近三年·实测来源·**编号=正文首次引用顺序且中英混排**;
11. 配图: 必要性优先、不超 5 张、图注在下居中、正文有"如图 N"引用;
12. 工具复检: `tools/check_doc.py` 零问题 + 个人信息待补清单已列;
13. 框架层级统一: 一级（一）～（五）→ 二级 1. 2. → 三级（1）（2）→ 正文枚举 ①…⑥, 小标题独立成行, 不与底板表头的 1.-5. 撞号(三-C 第 6 条)。

### 4. 专业范围审查要点(适用于体育·运动康复等专业)
- **越界信号**: 研究对象用"患者/病人"、干预含"药物/治疗/临床指标"、结论写"疗效/治愈率"、文献出自临床医学期刊;
- **改写方向**: 疾病分类 → 运动康复需求分层(如"伤后及功能性障碍型",并注明"经医学诊断明确"); 临床结局 → 体育测量与运动表现指标; 医学判断 → 明确由校医院承担,体育方负责运动处方执行与过程监控;
- **兜底动作**: 加"研究边界声明"——立足本专业范畴,研究运动端识别/处方/过程监控,不涉诊断·用药·临床疗效评价。

### 5. 本项目技术坑(操作备忘)
editor_sdk 实例会失效(`document is not open`)→ 重新打开取新 file_id; 表格 idx 随编辑漂移 → 每次改动前重新 `resolve_document_structure`; 改表须满格提交(缺合并占位格报 `invalid merge`); 原文件在微信/只读目录不可写 → 先另存到工作区再改; editor_sdk 不稳定时降级用 **python-docx** 直接改写单元格文本与插图(保留原格式)。

### 6. 反查对照法(2026-09-12 新增 · 拿"稿子 + 同底版范本"反查)
> 场景: 已有一份成稿(或上一轮生成的稿), 要判断它是否**符合本底板的要求**。**判据必须是文件自身的表头要求**(大方向 + 小方向), 不用外部标准、不用通用经验。

1. **先拆要求**: 按 二-E 轮次一 把底板的「大方向」「小方向」逐条抄出, 建立对照清单;
2. **六维对照**: ①结构完整性(5 大项是否齐全、顺序是否一致) ②各部分**字数配比** ③**子项覆盖**(文件原话的关键词逐条核) ④专业口径(见第 4 节) ⑤数字一致 ⑥工具复检;
3. ⚠️ **关键词检索须人工复核同义表述**: 本次"重点难点"在稿中写作"**重点与难点**", 机械检索判为漏项, 实际存在——凡判定"缺失"前必须回读原文确认;
4. **配比以范本实测字数为锚**: 有同底版范本时, 先量出范本各节字数作基准(如范本 三 正文 4784 字), 再定本稿目标区间; 无范本时按 三-H 配比 + 评分职能定;
5. **输出**: 一张"逐项对照结果表"(符合 ✅ / 存疑 🟡 / 不符合 🔴) + 问题清单 + 修订清单, 存档 `outputs/`。

### 7. 交付与文件处理铁律(2026-09-12 用户明确要求)
- **改稿一律就地写回原文件**: 用户提供文件要求修改 → 直接改写**该文件本身**; 改前先备份到 `outputs/(原名)_修订前备份_日期.docx`, 并在回复里说明备份名与位置。**不要只另存新文件**——用户打开原文件看不到变化, 会认为没有修改;
- **中间版本只放 `outputs/`**, 不落在用户桌面/工作目录;
- 交付时必须回报: 改了哪几处、改前改后数字(字数/配比)、备份位置、以及仍需用户补齐的字段清单;
- 若文件正在编辑器/预览中打开, 提醒用户**关闭后重新打开**再查看(否则看到缓存旧内容)。

### 8. 篇幅控制与精简手法(2026-09-12 实战)
- **目标锚点**: ①有同底版范本 → 用范本实测字数; ②无范本 → 按 三-H 配比(论证主体 60-75%)+ 评分职能(研究内容/思路方法最重);
- **精简优先级(从高到低)**: ①**合并内容重复的相邻段落**(最有效, 本次合并两段一次省 96 字); ②删修饰性铺陈与同义反复, 但**全部文献锚点必须保留**(删锚点会破坏"正文[n] ⊆ 文献表"); ③压缩长括注、并列枚举、政策文件罗列(留一份代表性文件即可); ④收紧句末总结语;
- ⚠️ **不可压缩项**: 学术价值 / 应用价值(评审据此判断"该不该做")、目标—内容—指标—方法对应、伦理说明与风险预案、关键难点与对策;
- ⚠️ **必须逐段实测字数**: 人工自估偏差极大(本次首轮"精简"自估减 300 字、实测仅减 86 字)。改完立刻脚本回测**各节**字数, 不达标再收一轮; 经验上"合并段落"比"逐字删"有效得多。

### 9. 段落级精准编辑法(稿件已含配图时 · 保护内嵌图片)
> 场景: 稿件的正文单元格内嵌有图与图注, 需要拆小标题、改段落文字、调整段序。**严禁整段重写**(会丢失内嵌图片与图注)。

1. 先 `ps = list(cell.paragraphs)` **固化段落对象引用**(后续全部按对象操作, 不按索引, 避免插入/删除后索引漂移);
2. 改文字: 保留首个 run、清空其余 run(`runs[0].text = 新文本`), 以**继承原有字体与缩进格式**;
3. 拆小标题: 把「标签。正文」拆成「独立小标题 + 正文」—— `copy.deepcopy(p._element)` 复制段元素 → `p._element.addprevious(新元素)` 插到原段之前 → 分别设置两段文字;
4. 调段序: `p12._element.getparent().remove(...)` + `p11._element.addnext(...)`;
5. **必做回读校验**: 段落数、图片数、图注、各节字数、五大部分标题是否齐全。

## 四 · 专属思考方向

### 1. 研究方向延续性
- 本项目与申请人长期研究方向的关系
- 前期成果(论文/项目/专利)的积累
- 形成研究方向的方法论体系
- 避免"追热点"式选题

### 2. 团队梯队配置
- 主持人(教师): 学术引领 + 关键技术攻关
- 骨干(青年教师/博士): 具体研究执行
- 研究生: 课题分担 + 学位论文支撑
- 本科生(可选): 基础工作 + 大创联动
- 分工明确,人岗匹配

### 3. 与教学结合
- 科研反哺教学(成果融入课程)
- 学生参与科研(培养创新能力)
- 教学案例/教材产出
- 体现"科教融合"

### 4. 成果转化潜力
- 研究成果的应用前景
- 产学研合作基础
- 专利布局策略
- 成果转化路径

### 5. 平台条件支撑
- 依托的实验室/研究中心
- 仪器设备条件
- 数据/样本资源
- 合作单位支撑

## 五 · 评审重点与常见雷区

### 评审重点
- 申请人研究方向积累
- 科学问题/技术问题的价值
- 研究方案的创新性与可行性
- 团队配置合理性
- 平台条件支撑度

### 常见雷区
- ❌ 研究方向频繁切换,无积累
- ❌ 团队拼凑,成员与项目无关
- ❌ 科研教学两张皮
- ❌ 创新点表述过度
- ❌ 经费预算不合理

## 六 · 成果形式要求与经费特点

### 成果形式要求

| 成果类型 | 合理预期 |
|---------|---------|
| 高水平论文 | 视项目级别定(SCI/CSSCI/核心) |
| 发明专利 | 有转化布局 |
| 研究报告 | 1-2 份 |
| 研究生培养 | 关联学位论文 |
| 教学成果 | 课程/教材/案例 |

### 经费特点
- 视项目级别差异大(纵向 2-60 万,横向数万-百万)
- 科目: 遵循相应管理办法
- 人力费: 纵向可列劳务费(学生),横向可列人力成本
- 周期: 1-4 年

## 与 orchestrator 的衔接

1. orchestrator 判定「教师科研」类型后,加载本 skill;
