## 二、执行流程（入口）

> 完整顺序见 `research-teacher-project` SKILL.md 开头「**执行总顺序（先看这里）**」。

```
①判形态(申报书/活页) → ②定题(二-A 符合性 → 二-C 七问两轮 → 二-D 三路径四要素)
→ ③★双轮确认门禁(二-E: 轮次一 文件解读+重点分级确认表 / 轮次二 题目·重点解决内容·解决方案·最终成果 四问对齐 —— 用户确认后才动笔)
→ ④三轮研究探讨 → ⑤正文写作(三-A~三-K) → ⑥文献实测(编号=正文首次引用顺序, 中英混排)
→ ⑦四道审查(三-L) → ⑧配图(如需要) → ⑨交付(13 项检查清单 + 写回原文件 + 待补清单)
```

## 三、工具用法

```
python tools/check_doc.py 稿件.md [--anonymous] [--min-chars N]
```
检查：中文字数 / 文献编号 1→N 正序 / 编号=正文首次引用顺序 / 正文 [n] ⊆ 文献表 / 匿名可疑项（--anonymous）/ 禁词与 AI 腔。**有问题退出码为 1**，可作生成流程硬门槛。
