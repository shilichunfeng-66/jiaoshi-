# 项目类型文件理解策略（前置流程引用）

> 用途：在「一开始」让用户确认制作什么类型的项目，据此采用**不同的文件理解方式**。由 orchestrator 前置流程引用。
>
> 核心理念：**不同项目类型，文件来源与母版确定方式不同**。必须先确认类型，再决定"怎么读文件、母版是谁、字体字号怎么定"。

## 一、项目类型确认（一开始必做）

让用户在以下 5 类中确认(口径与 orchestrator 统一;各线专属规则已下沉独立 skill):

| 类型 | 代码 | 文件来源特征 | 专属规则 |
|------|------|-------------|---------|
| 大创 | 大创 | 学校有固定母版 | `research-dachuang` skill |
| 教师科研 | 教师科研 | 通常一次性给多个文件(申报书/活页) | `research-teacher-project` skill |
| 论文 | 论文 | 用户可能做过论文作格式参考 | `research-writing` skill |
| 省部级(省市级课题) | 省市级课题 | 通常一次性给多个文件 | `project-types/省部级.md` |
| 国家级(国自然) | 国自然 | 官方有统一申请书模板 | `project-types/国家级.md` |

> **其他**(横向/校级/自定义)→ 走通用模板 + 底板解读流程(见 orchestrator「通用模板处理规则」)。

> 确认类型后，按下方对应的文件理解方式执行。**类型不同，读文件的方式不同，不可混用。**

## 二、各类型文件理解方式

### ① 大创
- **母版来源**: 学校母版 `schools/{学校}/大创/母版_申报书.docx`
- **理解方式**: 读取文件后，**优先使用母版**；除非用户明确要求更换母版，否则一律以学校母版为底板
- 字体字号: 按学校 format.md（池州=仿宋，阜阳=宋体）

### ② 国自然
- **母版来源**: 国家自然科学基金委官方申请书模板（标准统一）
- **理解方式**: 优先用官方模板作底板；无官方模板文件时，向用户索取
- 字体字号: 按官方模板要求

### ③ 教师科研 / 省市级课题（多文件识别）
- **文件特征**: 用户一次性提供**多个文件**，混杂了格式文件、规则文件、内容文件
- **三类文件的判据**（识别时据此判断）:

| 文件类型 | 判据 | 作用 |
|---------|------|------|
| **格式文件(母版)** | 空白未填写、带表格/边框/合并单元格/签字栏/盖章栏、可编辑的 .docx/.doc | 作为底板，后续内容在其上执行 |
| **规则文件** | 申报通知/指南/要求说明，含"申报条件""要求""注意事项""截止时间"等，常为 .pdf 或纯文本 | 提取格式要求、字数、提交材料清单 |
| **内容文件** | 参考范文/已填样例，含实际填写内容(项目名称、团队信息、正文) | 作为内容与格式的参照 |

- **理解方式（按序执行）**:
  1. **精准识别母版（格式文件）**: 按上表判据，从多个文件中挑出"空白 + 带表格/边框/签字栏"的格式化文件作为母版
  2. **区分其他文件**: 用上表判据区分**规则文件**（通知/要求）与**内容文件**（范文/样例），分别了解——规则文件提取格式要求，内容文件作为参照
  3. **格式文件确认**: 若格式文件比较明显 → 向用户**询问一次**确认"是否以该文件为母版"
  4. **格式文件不明显 → 索取空白模板**: 若无法从多个文件中判断哪个是格式文件，**向用户要一次空白模板**，自动当作母版
  5. **后续内容都在母版上执行**: 锁定母版后，所有生成基于母版进行
  6. **字体字号**: 参考用户提供的文件（规则文件/母版中的字体字号要求）；**文件无要求 → 默认阜阳师范大学大创的字体字号**（正文宋体小四、一级标题黑体四号）

### ④ 论文
- **重点**: 重点思考**论文题目**（题目凝练见 `project-types/论文.md`）
- **格式理解（按序执行）**:
  1. **询问用户有没有做过的论文**（作为格式参考）
  2. 加**几轮对论文格式的思考与理解**（结构/图表/引用/标题层级，逐项确认）
  3. **优先做能做到的格式部分**：格式不明确处先按通用惯例，不阻塞内容生成
  4. **格式理解到位后**，在理解好的格式上继续生成内容

## 三、通用原则

- **母版是唯一底板**: 无论哪种类型，一旦锁定母版/模板，边框、表格结构、签字栏、标签文字永不变，只在上面追加内容
- **字体字号兜底**: 文件/模板无字体字号要求时，默认阜阳师范大学大创（正文宋体小四、一级标题黑体四号）
- **拿不准就问**: 格式文件判断不清、母版不确定时，宁可问用户，不可猜
