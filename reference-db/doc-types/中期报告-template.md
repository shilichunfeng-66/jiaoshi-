# 中期检查报告 — 通用模板

> 本模板为学校无关的通用结构,学校格式规范覆盖之。

## 文档定位

中期检查报告回答"做得怎样"——项目执行到中期的进展情况,核心是对照原计划说明完成度,并说明调整与下一步。重在体现项目按计划推进且有阶段性成果。

## 通用章节结构

### 封面
- 项目编号 / 项目名称 / 项目类型
- 申请人 / 指导教师
- 中期检查日期

### 一、项目进展概述
- 项目总体进展(对照原计划)
- 已完成的主要工作
- 进度评估(提前/按期/滞后)

### 二、阶段性成果
- 已取得的成果(论文/实物/报告/数据)
- 成果清单表
- 与预期成果的对比

### 三、研究内容执行情况
- 逐项对照原研究内容,说明完成情况
- 已解决的关键问题
- 新发现/新进展

### 四、存在的问题与调整
- 执行中遇到的问题
- 已采取的应对措施
- 需要调整的内容(研究内容/方法/进度)
- 调整理由说明

### 五、经费使用情况
- 经费执行进度
- 分科目支出明细
- 经费使用合规性说明

### 六、下一步工作计划
- 待完成工作
- 时间节点安排
- 预期最终成果

### 签字栏
- 申请人签字 / 指导教师签字
- 学院检查意见
- 学校审查意见

## 内容侧重点

| 章节 | 核心 | 常见问题 |
|------|------|---------|
| 进展概述 | 总体进度 | 笼统无对照 |
| 阶段成果 | 实际产出 | 空话无实物 |
| 执行情况 | 逐项对照 | 跳过未完成的 |
| 问题调整 | 诚实说明 | 回避问题 |
| 经费使用 | 合规合理 | 执行率过低 |
| 下一步 | 具体可行 | 模糊 |
