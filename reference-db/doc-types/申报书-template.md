# 申报书/立项申请书 — 通用模板

> 本模板为学校无关的通用结构,学校格式规范覆盖之。生成时以学校 format.md 为准。

## 文档定位

申报书是项目立项的核心文件,核心回答两个问题:"为什么要做"(立项依据)和"怎么做"(研究方案)。重在说服评审人项目值得资助。

## 通用章节结构

### 封面
- 项目编号(可留空)
- 学校名称
- 项目类型(如: 国家级大学生创新创业训练计划项目)
- 项目名称
- 申请人/负责人
- 申报日期

### 基本信息表
- 项目名称 / 项目类型 / 实施时间
- 申请人或团队(姓名/年级/学院/专业/联系方式)
- 指导教师(姓名/研究方向/职称/主要成果)

### 一、项目实施的目的、意义
- (一)项目简介(300-500 字概述)
- (二)研究实施目的(研究要解决什么问题)
- (三)研究实施意义(创新点与项目特色)

### 二、项目研究内容和拟解决的关键问题
- (一)项目研究内容(分点阐述)
- (二)拟解决的关键问题(2-4 个)

### 三、项目研究与实施的基础条件
- (一)相关研究积累与已有工作基础
- (二)研究条件(设备/数据/平台)
- (三)申请人/团队前期成果

### 四、项目研究方案
- (一)研究目标
- (二)研究方法
- (三)技术路线(含流程图)
- (四)实施步骤

### 五、项目创新点
- 2-3 个创新点,每个有支撑逻辑

### 六、预期成果
- 成果清单(论文/实物/报告/专利)
- 成果形式与数量

### 七、进度安排
- 里程碑节点表

### 八、经费预算
- 预算明细表
- 预算说明

### 签字栏
- 申请人签字
- 指导教师签字
- 学院审核意见
- 学校审批意见

## 内容侧重点

| 章节 | 核心 | 常见问题 |
|------|------|---------|
| 目的意义 | 为什么做 | 空泛,无具体需求 |
| 研究内容 | 做什么 | 罗列过多,不聚焦 |
| 关键问题 | 难点在哪 | 与研究内容混淆 |
| 基础条件 | 凭什么做 | 与项目脱节 |
| 研究方案 | 怎么做 | 技术路线模糊 |
| 创新点 | 新在哪 | 夸大或无支撑 |
| 预期成果 | 产出什么 | 承诺过高 |
| 经费预算 | 花多少 | 科目不合理 |
