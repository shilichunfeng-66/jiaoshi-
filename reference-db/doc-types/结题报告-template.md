# 结题/验收报告 — 通用模板

> 本模板为学校无关的通用结构,学校格式规范覆盖之。

## 文档定位

结题报告回答"做出了什么"——项目完成后的总结性文件,核心是展示研究成果、说明目标达成情况、总结经验与不足。重在体现项目圆满完成且有实质产出。

## 通用章节结构

### 封面
- 项目编号 / 项目名称 / 项目类型
- 申请人 / 指导教师
- 结题日期

### 一、项目完成情况概述
- 项目总体完成情况(对照原计划)
- 目标达成度评估
- 主要工作回顾

### 二、主要研究成果
- (一)研究成果清单(论文/专利/实物/报告/数据)
- (二)成果详细说明(每项成果的内容与价值)
- (三)成果与预期目标的对照

### 三、项目创新点总结
- 实际实现的创新点
- 创新点的学术/应用价值
- 与申报书承诺的对照

### 四、研究内容完成情况
- 逐项对照原研究内容
- 已完成/部分完成/未完成说明
- 关键问题解决情况

### 五、成果应用与推广前景
- 成果的应用情况
- 推广价值与路径
- 社会/经济效益

### 六、经费决算
- 经费执行总结
- 分科目决算明细
- 结余/超支说明

### 七、项目总结
- 主要经验
- 存在不足
- 后续研究展望

### 附成果附件
- 论文复印件/录用通知
- 专利证书
- 实物照片/演示
- 其他证明材料

### 签字栏
- 申请人签字 / 指导教师签字
- 学院验收意见
- 学校审批意见

## 内容侧重点

| 章节 | 核心 | 常见问题 |
|------|------|---------|
| 完成情况 | 对照原计划 | 回避未完成项 |
| 研究成果 | 实物证据 | 空话无附件 |
| 创新点 | 实际价值 | 申报书原话照搬 |
| 应用前景 | 落地路径 | 夸大前景 |
| 经费决算 | 合规完整 | 科目混乱 |
| 项目总结 | 诚实反思 | 只讲成绩不讲不足 |
