> 数据来源：国家自然科学基金大数据知识管理服务门户 `https://kd.nsfc.cn/finalSearchList`（BrowserSkill/bsk 实测；检索词"人工智能"，近五年，共 784 项，本次采样 100 项：10 页 × 10 项）。
> 字段：项目名称 / 批准号 / 申请代码 / 项目类别 / 负责人 / 资助经费 / 批准年度 / 结题年度 / 依托单位 / 关键词（5 个）。
> 用途：补齐现有 skill 在**理工科/交叉学科（AI 类）**题目命名、经费周期、关键词写法上的空白；与 `社科基金题目命名规律-人民网数据库实测.md` 互为补充。
>
> ⚠️ **数据性质说明（重要）**：本库采录的是**项目元数据片段**（题目、关键词、申请代码、类别、经费、批准/结题年度、单位），**不含项目正文**（申请书/结题报告全文不在此列）。因此本文件提炼的是 **题目命名方式、主题构造方式、关键词组织方式、规模与周期规律** 四个层面的规律；不涉及论证结构、研究内容的段落写法（那部分另见选题依据三层漏斗与体联申报书范本）。

## 二、题目命名范式（AI/理工交叉类 · 6 式）

| 范式 | 结构 | 真实样例 |
|------|------|---------|
| ① 基于式 | `基于人工智能的 + [对象] + [动作] + 研究` | 《基于人工智能的绘画艺术关键技术研究》《基于人工智能和影像组学肺癌免疫治疗疗效评估研究》 |
| ② 驱动式 | `人工智能驱动的 + [对象] + [动作]` | 《人工智能驱动的药物分子和蛋白质设计》《人工智能驱动的药物相互作用预测方法及发生机制研究》 |
| ③ 辅助式 | `人工智能辅助的 + [对象] + [技术/研究]` | 《人工智能辅助的酶定向进化研究》《人工智能辅助细胞分选芯片智能设计关键技术研究》 |
| ④ 面向式 | `面向 + [场景/任务] + 的 + 人工智能 + [技术] + 研究` | 《面向司法实践的人工智能决策辅助的关键技术研究》《面向技术同化的人工智能在医疗决策中的影响机制研究》 |
| ⑤ 影响机制式（管理/社科交叉） | `人工智能 + [发展/技术变迁] + 对 + [对象] + 的影响/机制研究` | 《人工智能对企业出口产品成本加成率的影响研究》《人工智能发展对碳排放影响的机理和量化评估研究》 |
| ⑥ 理论型（心理学/行为） | `[对象] + 对 + 人工智能的 + [认知/信念]：形成机制与行为响应` | 《消费者对人工智能的朴素信念：形成机制与行为响应》 |

**长度**：多在 **12-25 字**（比社科题目短，信息密度更高）；技术类常以"**关键技术研究**"收尾，机制类以"**影响机制/机理研究**"收尾。

**高频题眼**：驱动 / 辅助 / 赋能 / 面向 / 基于 / 智能设计 / 预测 / 评估 / 优化 / 关键技术 / 影响机制 / 机理 / 量化评估。

## 三、关键词写法规律（每项固定 5 个）

从 500 个关键词（100 项 × 5）统计，结构为**四层组合**：

| 层 | 作用 | 高频实例 |
|----|------|---------|
| 方法层 | 主技术 | 人工智能(74) / 深度学习(14) / 机器学习(7) / 神经网络 / 密度泛函理论计算 / 分子动力学模拟 |
| 对象层 | 应用领域 | 影像组学(4) / 药物设计(3) / 计算机辅助诊断(3) / 鼻咽肿瘤 / 数字病理 / 蛋白质 / 铜纳米团簇 |
| 技术层 | 具体手段 | 预测模型(4) / 虚拟筛选(3) / 网络药理学(3) / 数据挖掘(3) / 光谱实时预测 |
| 理论/机制层 | 解释框架 | 复杂网络(3) / 心理机制(2) / 催化作用机理(2) / 数据驱动 |

**写法提示**：主关键词（人工智能）必列，其余 4 个按"方法—对象—技术—机制"顺序铺开，避免 5 个词同一层（如全写深度学习/机器学习/神经网络/强化学习）。

## 三-补 · 精华浓缩：四条可复用规律（从元数据片段反推）

即使只有"题目+关键词+类别+经费+年度"这些片段，也能反推出四条稳定规律——这就是可直接搬到项目上的精华：

**规律 1｜主题构造只有三条路径，先选路径再拟题**
| 路径 | 主题句模式 | 适用 |
|------|-----------|------|
| 技术驱动型 | `[方法] + 驱动的 + [对象] + [动作]` | 有明确新技术抓手 |
| 场景问题型 | `面向 + [真实场景/任务] + 的 + [方法] + [技术] + 研究` | 有明确应用场景与痛点 |
| 机制解释型 | `[现象/技术] + 对 + [对象] + 的 + 影响机制/机理 + 研究` | 偏社科/管理/行为交叉 |
> 选题时先从三条路径中选一条，题目表述、研究内容、关键词都随之统一——避免"技术与场景混搭、机制与对策混杂"。

**规律 2｜题目=四要素定式**
`方法词（驱动/辅助/基于/面向）+ 研究对象 + 研究动作 + 落点后缀`
- 方法词只在四种里选一种，不叠加；
- 落点后缀按类型定：技术类用"关键技术研究/方法研究/模型构建"；机制类用"影响机制研究/机理研究/量化评估"；
- 长度 12-25 字，比社科题目短。

**规律 3｜关键词=四层五词**
方法层 1 + 对象层 1-2 + 技术层 1 + 机制层 1（顺序即层级，避免同层堆叠）。词库直接取真实高频词（人工智能/深度学习/影像组学/预测模型/复杂网络…）。

**规律 4｜类别—经费—周期三者对应研究颗粒度**
| 类别 | 经费（万元） | 周期 | 研究颗粒度 |
|------|------------|------|-----------|
| 青年基金 | 20-30 | 3 年 | 单一问题做深 |
| 面上项目 | 48-60 | 3-4 年 | 2-3 个问题成链 |
| 重点/重大研究计划 | 200-300 | 4-5 年 | 体系化构建 |
> 写研究内容时按颗粒度匹配：申报青年项目却写"体系构建"，或申报重点项目只写一个点，都是典型的层级错配。



## 四、对现有 skill 的优化方案

### 方案 1｜题目命名库扩充（优先级 P0）
- 在 `社科基金题目命名规律` 同目录新增本文件后，**命名参照库分两册**：社科类（8 类项目、6 式）+ 理工交叉类（本册，6 式）；
- `research-teacher-project` 二-C 第⑤问"是否达到科研项目水平"增加**学科适配判断**：社科选题比对社科册，理工/交叉选题比对理工册（长度更短、更重"方法+对象+关键技术"）。

### 方案 2｜题目命名的"方法要素"校验（P0）
- 二-C 五问中增加一问（对含新技术/新方法的题目）：**方法在题目中是否可辨识**（驱动/辅助/基于是最基本的三种写法），无名无姓的"智能化研究"不达标。

### 方案 3｜经费与周期参考入库（P1）
- 教师科研线"预期成果/研究计划"处补参考值：**青年 20-30 万 / 面上约 48-60 万 / 重点 200-300 万；周期 3-4 年**（实测主流 3-4 年结题）；
- 申报书"研究计划"分段建议按 3-4 年节奏排（前 1 年打基础、中间 2 年攻关、末 1 年验证与成果）。

### 方案 4｜关键词矩阵写法固化（P1）
- 二-A 关键词矩阵增加"四层结构"要求：方法层 / 对象层 / 技术层 / 机制层，每层至少 1 词，共 5 词；
- 词库直接取用本文件第三节实例（真实关键词，非编造）。

### 方案 5｜结题成果表述参照（P2）
- 结题报告全文在 kd.nsfc.cn / 共享服务网公开，可取"预期成果怎么写、结题成果怎么表述"的真实范式；建议在教师科研线"预期成果"模板中挂该渠道。

### 方案 6｜跨学科申报路径提示（P2）
- 实测显示 AI 类项目分布于 H/G/F/B/E/T/C 等 9 个大类 → 教师科研线增加提示：**同一选题可通过不同申请代码/学科口径申报**，先选落点学科再定题目表述（学科口径影响评审口径）。
