# 评审自评量表 · 模板（教师科研 / 申报书 / 活页 通用）

> 用法：生成稿完成后逐维打分（1-5 分），在"打分依据"里写**具体证据**（指向章节或句子），不留空。
> 规则：任一维度 < 3 分 → 回对应章节修改后重评；总分 < 20 分 → 不建议提交。
> 配套工具：`tools/check_doc.py`（字数 / 文献锚点 / 正序 / 匿名 / 禁词自动回检）。

## 评审追问八问自测（逐问一句话作答，答不上即视为失分项）

1. 科学问题是什么？
2. 与已有研究相比新在哪？
3. 目标能否考核？
4. 关键难点如何突破？
5. 数据/样本从哪来、够不够？
6. 团队与平台能否支撑？
7. 成果是否可达、承诺是否过高？
