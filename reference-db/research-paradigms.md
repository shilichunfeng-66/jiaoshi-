# 科研范式分类与必加要素（项目思考环节引用数据）

> 用途：在「第一步确定题目」之后、「框架设计」之前，判定项目属于哪类科研范式，据此决定正文中**必须加入哪些方法论要素**。由 orchestrator 的「步骤 2.6 项目思考环节」引用。
>
> 原则：**载体类型决定格式，科研范式决定内容要素**。两者正交，必须分开判定。同一载体（如大创）下可能属于不同范式。

## 一、科研范式五分类

| 范式 | 编号 | 典型题目特征 | 一句话定位 |
|------|------|------------|-----------|
| 调查/实证类 | ① | 探究影响路径、现状、规律、需求、满意度、影响因素 | 通过数据收集回答"是什么、为什么、怎么变" |
| 实验/技术类 | ② | 材料、医学、工程、算法、性能优化、数据密集型 | 通过实验/仿真验证"能不能、好不好、高多少" |
| 设计/工程类 | ③ | 造系统、产品、方案、模型、平台 | 通过设计与实现交付"可用的东西" |
| 政策/文献类 | ④ | 政策分析、文本研究、历史梳理、制度变迁 | 通过文本分析回答"如何演变、如何解读" |
| 纯理论类 | ⑤ | 数学推导、理论建构、纯学术思辨 | 通过逻辑推演回答"为什么成立" |

## 二、每类范式的必加方法论要素

> 判定范式后，正文中**必须出现**对应要素；缺失即视为内容不完整，由 quality-check 的「范式特定 Checklist」校验。

### ① 调查/实证类
- **调研类型**：横断面调查 / 纵向追踪 / 普查 / 抽样调查 / 个案研究，说明选择理由
- **调研对象与样本设计**：研究对象是谁、抽样方式、样本量估算
- **调研方法**：问卷 / 访谈 / 观察 / 案例，说明选型理由
- **变量与指标体系**：自变量/因变量/控制变量，测量工具
- **数据分析方法**：描述统计 / 回归 / 因子分析等（可说明工具如 SPSS/Python）
- **信效度保障**：问卷信效度检验、数据质量控制
- 适用：探究影响路径、发展趋势、现状调查等题目；**同样适用于论文**

### ② 实验/技术类
- **实验设计**：变量控制、分组、重复数、对照设置
- **材料与方法**：所用材料/设备/试剂、制备或实现流程
- **性能指标**：评价维度（如力学性能、准确率、效率）
- **性能目标预估**（有条件才做，见第四节铁律）：基于真实文献参数，设定"拟达到/预期"目标值
- **对照与验证**：与现有方法/材料的对比基准
- 适用：材料制备、医学干预、算法优化、工程性能等题目

### ③ 设计/工程类
- **需求分析**：用户/场景需求，功能与非功能需求
- **系统/方案架构**：模块划分、数据流、技术选型
- **技术路线**：分阶段实现路径
- **方案论证**：可行性与创新性论证
- **原型/实现与验证**：交付物形态 + 验证方式
- 适用：系统开发、产品设计、平台搭建、方案设计等题目

### ④ 政策/文献类
- **政策/文献库建设**：文本来源、时间范围、筛选标准
- **文本分析方法**：内容分析（编码）/ 政策文本计量 / 文本挖掘（词频、共现、主题模型）
- **演进脉络或比较框架**：阶段划分或横向比较维度
- **理论与实践对接**：政策解读 + 地方/案例佐证
- 适用：政策演进、文本分析、历史梳理、制度研究等题目

### ⑤ 纯理论类
- **理论框架**：核心概念界定、理论前提
- **研究假设或命题**：可检验/可推导的命题
- **证明/推导逻辑**：逻辑链条、模型构建
- **边界条件**：结论的适用前提与局限
- 适用：数学证明、理论建模、纯学术思辨等题目

## 三、能力匹配评估（借鉴 Supervisor-Skills idea-evaluator）

判定范式后，立即评估「该题目在当前申报者身份下是否可执行」：

| 身份 | 能力边界 | 超出时的处理 |
|------|---------|-------------|
| 本科生（大创） | 方法论可学、设备可得、周期 1-2 年 | 复杂方法降格为"初步探索"，或标注"留待后续研究" |
| 研究生 | 可承担一定深度的方法论 | 但仍不拔高到"国际领先" |
| 教师/科研人员 | 可承担完整研究设计 | 按规范完整展开 |

- **可执行** → 正常展开
- **部分超出** → 保留框架、标注局限（如"拟采用…作为探索性尝试"）
- **明显超出** → 明确写入"本项目不作…，留待后续"，不硬凑

## 四、理工类"性能目标预估"铁律（沿用数据铁律）

> 数据密集型（实验/技术类）题目在**用户未提供数据**时，是否补"数据预估"，按下述规则：

1. **只做"有依据的目标预估"，不做"虚拟实验数据"** —— 绝对不编造实测数据（如"本材料拉伸强度达 XX MPa"这种伪造的实验结果）
2. **有真实文献参数可外推** → 用限定语"拟达到 / 预期 / 争取达到" + 标注文献来源，且说明假设条件
3. **无文献支撑、无法合理估算** → **明确不加**，不硬凑数据
4. 预估数据的位置：研究现状（引用文献真实参数）、关键问题（预期目标量级）、技术路线（工艺参数参照）、可行性（已有成果支撑）
5. 申报书阶段**点到为止**（2-4 处），不堆大张数据比对表（那是论文/结题的事）

## 五、评审重点（按范式，用于审核口径）

| 范式 | 评审重点 |
|------|---------|
| ①调查/实证类 | 样本设计是否科学、变量界定是否清晰、结论是否有数据支撑 |
| ②实验/技术类 | 实验设计是否可重复、性能目标是否有依据、方法是否可行 |
| ③设计/工程类 | 需求是否真实、架构是否合理、能否落地交付 |
| ④政策/文献类 | 文本来源是否权威、分析方法是否规范、结论是否审慎 |
| ⑤纯理论类 | 逻辑是否严密、假设是否成立、结论边界是否清晰 |
