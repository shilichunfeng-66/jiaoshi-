## 五、与其他工作区的关系

- **论文工作区** `D:\论文工作区` 有独立的一套流程与检索规范（详见其 README）；本索引只管主工作区 `D:\科研文件\reference-db`；
- skill 与 reference-db 的对应（**四类线平级**）：`research-dachuang`（大创线）· `research-teacher-project`（教师科研线）· `research-writing`（论文线）· `research-other-projects`（其他项目线：国家级/省部级/校级/横向/通用模板）· `research-project-orchestrator`（调度中枢 + 通用铁律）；
- 新增/改名文件后，**同步更新本索引**；跨工作区复制 skill 用 `tools/skill_sync.py`（检查/同步）；稿件回检用 `tools/check_doc.py`（字数/文献锚点/正序/匿名/禁词）。
