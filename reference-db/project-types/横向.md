# 横向/企业合作项目 — 思考方向

## 项目定位

横向项目是企业/事业单位委托高校团队开展的技术开发、技术咨询、技术服务类项目。以解决实际问题为导向,强调可交付、可量化、可验收。

## 专属思考方向

### 1. 企业实际需求精准理解
- 明确企业的核心痛点(不是表面需求)
- 需求来源: 企业提供的需求说明/现场调研
- 区分"想要"与"需要"
- 技术指标基于真实场景

### 2. 技术指标可量化
- 交付物的技术参数明确可测
- 如: 识别准确率≥95%、处理速度≥100件/分钟
- 验收标准清晰(测试方法/数据集)
- 避免模糊表述("提升效率""优化性能")

### 3. 知识产权归属清晰
- 既有知识产权归属(双方各自带入的)
- 新产生知识产权归属(通常归企业或共有)
- 论文发表/专利申请的约定
- 保密义务与期限

### 4. 交付物明确
- 交付物清单(软件/硬件/报告/数据)
- 交付时间节点
- 验收方式与标准
- 后续维护/升级约定

### 5. 经费与工期匹配
- 经费覆盖研发成本(人力/材料/设备)
- 工期合理(不过度乐观)
- 里程碑付款节点
- 留有合理缓冲

## 评审重点

- 需求理解的准确性
- 技术方案的可行性
- 交付物的明确性
- 经费工期的合理性
- 知识产权安排

## 常见雷区

- ❌ 需求理解偏差,做出来的东西企业不要
- ❌ 技术指标模糊无法验收
- ❌ 工期估计过短
- ❌ 知识产权约定不清引发纠纷
- ❌ 经费分配不合理(人力成本过低)

## 成果形式要求

| 成果类型 | 特点 |
|---------|------|
| 软件/系统 | 源码+文档+部署 |
| 技术报告 | 含测试数据/对比分析 |
| 样品/样机 | 可演示可测试 |
| 技术标准 | 企业内部标准/规范 |
| 专利 | 按合同约定归属 |

## 经费特点

- 额度: 视项目复杂度,数万至数十万
- 科目: 较纵向宽松,可列人力成本
- 税费: 需考虑税费和管理费
- 周期: 通常 6 个月-2 年
