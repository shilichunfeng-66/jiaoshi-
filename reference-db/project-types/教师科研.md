# 教师科研项目 — 思考方向

> **提示(2026-09-09)**: 教师科研线的完整生成规则(描述逻辑/四轮梳理/活页子流程/三层漏斗/写作模板/结构范本等)已下沉到 `.workbuddy/skills/research-teacher-project/SKILL.md`。本文件保留「专属思考方向」作为思考素材,由该 skill 引用,二者不重复维护。

## 项目定位

教师科研项目指由高校教师主持的各类纵向/纵向科研课题,区别于学生主持的大创项目。教师作为主持人承担主要研究责任,学生(研究生/本科生)作为团队成员参与。本文件侧重教师作为申请人的思考方向。

## 专属思考方向

### 1. 研究方向延续性
- 本项目与申请人长期研究方向的关系
- 前期成果(论文/项目/专利)的积累
- 形成研究方向的方法论体系
- 避免"追热点"式选题

### 2. 团队梯队配置
- 主持人(教师): 学术引领 + 关键技术攻关
- 骨干(青年教师/博士): 具体研究执行
- 研究生: 课题分担 + 学位论文支撑
- 本科生(可选): 基础工作 + 大创联动
- 分工明确,人岗匹配

### 3. 与教学结合
- 科研反哺教学(成果融入课程)
- 学生参与科研(培养创新能力)
- 教学案例/教材产出
- 体现"科教融合"

### 4. 成果转化潜力
- 研究成果的应用前景
- 产学研合作基础
- 专利布局策略
- 成果转化路径

### 5. 平台条件支撑
- 依托的实验室/研究中心
- 仪器设备条件
- 数据/样本资源
- 合作单位支撑

## 评审重点

- 申请人研究方向积累
- 科学问题/技术问题的价值
- 研究方案的创新性与可行性
- 团队配置合理性
- 平台条件支撑度

## 常见雷区

- ❌ 研究方向频繁切换,无积累
- ❌ 团队拼凑,成员与项目无关
- ❌ 科研教学两张皮
- ❌ 创新点表述过度
- ❌ 经费预算不合理

## 成果形式要求

| 成果类型 | 合理预期 |
|---------|---------|
| 高水平论文 | 视项目级别定(SCI/CSSCI/核心) |
| 发明专利 | 有转化布局 |
| 研究报告 | 1-2 份 |
| 研究生培养 | 关联学位论文 |
| 教学成果 | 课程/教材/案例 |

## 经费特点

- 视项目级别差异大(纵向 2-60 万,横向数万-百万)
- 科目: 遵循相应管理办法
- 人力费: 纵向可列劳务费(学生),横向可列人力成本
- 周期: 1-4 年

## 项目资料获取渠道（2026-09-10 实测核实 · 用于立项依据与选题参考）

| 渠道 | 内容 | 说明 |
|------|------|------|
| **科学基金共享服务网** `npd.nsfc.gov.cn` | 已结题项目的《结题/成果报告》**全文** | 基金委准予结题后公布（部分公开），是最接近"项目全文"的公开渠道 |
| **国家科技报告服务系统** `www.nstrs.cn` | 科技报告全文 | 与共享服务网联动 |
| **NSFC 官网「优秀成果选编」** `nsfc.gov.cn/p1/3184/yxcgxb.html` | **成果简介汇编**（非全文） | 每五年一辑（已出八辑），每学科遴选 4-5 项，由科学出版社出版；官网提供 PDF，实测为**纯图片版**（240 页无文本层，需 OCR 才能取字）；内容要素＝成果名称/负责人团队/资助项目编号/成果内容/应用案例/图照 |
| 项目申请书全文 | **不公开** | 任何官方渠道均不提供基金申请书全文，勿在网络流传件上取用 |

> 使用提示：写立项依据/研究现状时，可从共享服务网获取结题报告全文作真实参考；「优秀成果选编」适合看国家级成果的表述范式与成效写法，但不含申请书的论证结构。
